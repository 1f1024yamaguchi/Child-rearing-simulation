イベント制作ツールの使い方

メリット／デメリットのイベントを、スクリプトを書かずに作ったり直したりするための手引きです。いつ出すか（年月日・条件）、選択肢（1〜4つ）、選んだあとの展開（ストーリー分岐）まで、1つのウィンドウで決められます。

しくみ どこで何をする ウィンドウの見方 新しく作る いつ出すか 選択肢 ストーリー分岐 見て確かめる ストーリーの文章 気をつけること

0しくみ

イベント1つ＝アセット1つ（EventData）です。Resources/Events に置いたアセットは、ゲームが自動で読み込みます。登録の作業はありません。

① 中身：EventData Assets/Maruyama/Resources/Events/

タイトル・説明・画像、いつ出すか（出方と条件）、選択肢（ラベルと効果）。編集ウィンドウで作ります。

→
② 出す係 EventManager / StoryEventScheduler

抽選と決まった日は EventManager、「続き」と「条件を満たしたら」は StoryEventScheduler が毎日確かめて、カードを順番待ちに入れます。

→
③ 記録：StoryState 本編シーンの「Story」

起きたイベント・選んだ選択肢・フラグ・予約中の続きを覚えます。セーブされます。本編シーンを開くと自動でできます。

1どこで何をするか

やりたいこと場所
イベントを作る・直すメニュー「子育て › イベント › 編集ウィンドウ」。EventData の Inspector の「編集ウィンドウで開く」からも開けます
いつ出すかを決める編集ウィンドウの「いつ出るか」と「出る条件」
選択肢と効果を決める編集ウィンドウの「選択肢」
選んだあとの展開をつなぐ選択肢の中の「ストーリー」欄（フラグ・趣味・特性・続き・ストーリーを出す）
フラグを作るProject で右クリック › 作成 › 子育て › ストーリー › フラグ
全部のイベントがいつ出るかを見る編集ウィンドウのいちばん下「すべてのイベント」の［年表］
直すところを探す編集ウィンドウの「チェック」（✕＝直す、⚠＝確かめる）
再生中に出してみる再生中に編集ウィンドウの「今すぐ出す」
分岐の先を早送りで確かめるメニュー「子育て › デバッグツール」の「選択肢の固定」＋年齢ジャンプ
古いイベントに選択肢 ID を付けるメニュー「子育て › イベント › 選択肢に ID を付ける」（1回だけ）

2ウィンドウの見方

上から順に埋めていけば1つのイベントができます。値はその場でアセットに書き込まれ、Ctrl+Z で戻せます。

上半分：基本・いつ出るか・出る条件

  1. 1
    まとめ中身を1〜2行の文にしたもの。「メリット・抽選。6〜9歳。一生に1回…選択肢3つ：通わせる（−5,000円・趣味+20…）」のように出ます。入れたものが思いどおりか、ここで読んで確かめます。
  2. 2
    基本ID・メリット／デメリット・タイトル・説明・画像。説明に {name} と書くと、ゲームでは子どもの名前（みらい）に置き換わります。画像は空でもかまいません。描いてほしい絵があれば「絵の指示メモ」に書きます。
  3. 3
    いつ出るか出方を5つから選びます（4章）。抽選なら重み・クールダウン・「一生に1回だけ」。
  4. 4
    出る条件すべて満たしたときだけ出ます。［＋条件を足す ▼］から選ぶと、その場で中身を入れられます。新しく作った条件はイベントのアセットの中に入るので、ファイルは増えません。

選択肢

  1. 1
    出す条件（任意）満たさないと、その選択肢は灰色になって押せません。空ならいつでも押せます。
  2. 2
    効果1行＝種類・だれに・どれだけ・長さ。お金は円で入れます（−5000）。
  3. 3
    ストーリーフラグを立てる／消す、趣味を決める、特性を付ける、続きを予約（○日後）、ストーリーを出す。使うものだけ入れます（6章）。
  4. 4
    カードのチップゲームのボタンの上に出る小さな札のプレビュー。お金はチップではなくボタンの文字に「（−5,000円）」と付きます。

下半分：つながり・チェック・置き場所

  1. 1
    ストーリーのつながりこのイベントの前後。「来る道」「行く道」「このイベントを条件にしているもの」「使っているフラグ」。［移動］でそのイベントへ移れます。
  2. 2
    チェック✕ は直さないと正しく動かないもの、⚠ は確かめてほしいもの。保存はどちらでもできます。
  3. 3
    置き場所Resources/Events の外にあるとゲームに出ません。そのときは［移動する］が出ます。

3新しく作る

  1. 編集ウィンドウの［新しく作る ▼］からテンプレートを選び、ファイル名を決めます（例：Event_Merit_Baseball）。ID はファイル名から自動で付きます（merit_baseball）。
  2. 「基本」にタイトルと説明を書きます。
  3. 「いつ出るか」と「出る条件」を決めます。
  4. 選択肢のラベルと効果を入れます。分岐させるなら「ストーリー」欄も。
  5. 「チェック」に ✕ が無いことを確かめます。
  6. 再生して「今すぐ出す」で見てみます（7章）。
テンプレート最初に入る内容
空何もなし
抽選のメリット／デメリット出方＝抽選、選択肢2つ
決まった日出方＝決まった日（1回）、選択肢1つ「わかった」
続き出方＝続き、選択肢1つ
条件を満たしたら出方＝条件を満たしたら、「一生に1回」の条件つき
分岐の入口（2択）抽選・一生に1回、選択肢2つそれぞれに「続きを予約」（180日後）

［複製して作る］は、今のイベントをコピーして ID だけ付け直します。似たイベントを作るときに便利です。

4いつ出すか

出方（5つ）

出方出るとき向いているもの
抽選月ごとの抽選で、出る条件を満たすものから重みで選ばれる風邪・急な出費・地域のイベント
決まった日「○歳○月○日に1回だけ」か「毎年○月○日（○歳〜○歳）」に必ず誕生日・お年玉・入学
続き別のイベントの選択肢が「○日後に続きを予約」したときだけ。抽選には入らない体験会 → 初めての試合
条件を満たしたら出る条件を満たした最初の日に1回だけストレスが限界になったら、野球をやめたい
コードからコードから EventManager.Instance.Enqueue を呼んだときだけミニゲームの結果など
ポイント　「続き」は予約された日が来た時点で、そのイベントの「出る条件」をもう一度確かめます。満たしていなければ出ずに捨てられます（例：その日までに野球をやめていたら試合は来ない）。

出る条件の部品

部品決められること説明の例
年齢満年齢の範囲3〜5歳
日付の範囲○歳○月○日〜○歳○月○日6歳4月1日〜6歳7月31日
月1〜12月のチェック冬（12・1・2月）
学年年少〜高3などの範囲（4月1日時点の年齢から）小3〜小6
ストレス段階子・母・父・親の平均の段階子のストレスが危険〜限界
子の体調／子どもの値体調・成績・趣味Lv の範囲、趣味の種類趣味「スポーツ」
所持金○円以上／以下所持金が 100,000円以下
支援制度制度を受給中／受けていない予防接種の補助を受けていない
特性・状態だれかが特性・状態を持っている／いない子が「風邪気味」
支援条件の流用支援制度の申請条件をそのまま使う年収 960万円以下
前の選択・履歴イベントが起きた／起きていない、選択肢を選んだ／選ばなかった「野球教室の体験会」で「通わせる」を選んだ
フラグフラグが立っている／いない「野球をやっている」が立っている

「選ばなかった」は「起きていて、別の選択肢を選んだ」という意味です。まだ起きていないときは満たしません。

5選択肢

基本は2つ。必要なときだけ1・3・4つにします（5つ以上は ✕）。4つのときは 2×2 で並ぶので、ラベルは短めに（10文字を超えると ⚠）。

カードの大きさ　絵・タイトル・説明・選択肢を上から自動で並べ、中身に合わせて高さが決まります。絵を設定しなければ上は空かず、文章が詰まります。絵は横いっぱい（高さ130）に収まる大きさで入り、縦横の比率は保たれます。

画面に入りきらないときは、カードごと自動で縮みます。メリットとデメリットの2枚が同時に出るときは、横に並べるぶん少し小さくなります。
  • 選択肢 ID（go later など）は、「何を選んだか」の記録に使います。新しく足すと c1, c2 … が自動で付きます。ゲームに出したあとは変えないでください（セーブの記録と合わなくなります）。
  • 家計簿の種類：お金が動くとき家計簿に載せる種類（病院なら「医療」）。
  • 保険診療の自己負担：オンにすると、医療費助成の対象になり、ボタンに「助成で ○円」などと出ます。

6ストーリー分岐を作る

選んだ選択肢でその後が変わるようにします。例として「野球教室の体験会」で「通わせる」を選ぶと野球が趣味になり、半年後に試合が来る流れを作ります。

野球教室の体験会抽選・6〜9歳・一生に1回
  • 通わせる → フラグ・趣味・続きを予約
  • 今回はやめておく
→
初めての試合続き（180日後）
  • 応援に行く
  • 仕事で行けない
→
少年野球の大会 など抽選・条件：フラグ「野球をやっている」
  • 職業「プロ野球選手」の条件にも使える
  1. フラグを作る：Project で右クリック › 作成 › 子育て › ストーリー › フラグ。ID（baseball）と表示名（野球をやっている）を入れます。趣味の呼び名を使うなら「趣味の呼び名」をオンにして「野球」、分類を「スポーツ」に。
  2. 入口のイベントを作る：テンプレート「分岐の入口（2択）」で作り、選択肢1を「通わせる」に。
  3. ストーリー欄を埋める：フラグを立てる＝野球をやっている、趣味を決める＝スポーツ、続きを予約の［＋新しく作る］で「初めての試合」を作り、日後を 180 に。
  4. その先のイベント：「少年野球の大会」などの出る条件に「フラグ」を足して「野球をやっている」を選びます。
  5. やめる道も作る：「野球をやめたい」の選択肢で「フラグを消す」を使うと、それ以降の野球のイベントは出なくなります。

趣味の呼び名（プレイヤーにどう見えるか）

趣味の種類は「スポーツ」のままですが、呼び名つきのフラグが立っていると画面では「野球」と出ます。子どもカードのプロフィール（8歳・野球が好き）、趣味の行、効果のチップ（野球 +20／趣味：野球）が置き換わります。フラグを消すと「スポーツ」に戻ります。

フラグを使うか、前の選択を使うか　1つのイベントの結果だけで決まるなら「前の選択・履歴」の条件で足ります（フラグ不要）。いくつものイベントで立てたり消したりする状態（今も野球を続けているか）はフラグにします。

7見て確かめる

再生中だけの欄

本編シーンを再生すると、ウィンドウに「再生中だけ」の欄が出ます。

  • 今の条件の判定：出る条件の1つずつに ✓／×。出ない理由がすぐ分かります。
  • 今すぐ出す（条件を無視）：カードを本番どおり出します。
  • ストーリーの状態：立っているフラグ、選んだ選択肢の履歴、予約中の続き（○歳○月○日／あと○日）。
注意　再生中に変えた値は、アセットにそのまま残ります（再生を止めても戻りません）。

年表

分岐の先を早送りで確かめる

  1. メニュー「子育て › デバッグツール」を開きます（再生中）。
  2. 「選択肢の固定」でイベントと選択肢をドロップダウンから選び、［固定を追加］。再生を止めても残ります。
  3. 「オート」をオンにして、年齢ジャンプで早送りします。固定したイベントでは必ずその選択肢が選ばれます。

8ストーリーの文章（チュートリアル形式）

選んだあとに、画像と説明文のページで「お話」を見せられます。作り方はチュートリアル制作ツールと同じです（チュートリアル制作ツールの使い方）。

出し方設定する場所
選んだ直後に出すイベントの選択肢のストーリー欄「ストーリーを出す」にチュートリアルを入れる
日をおいて出すチュートリアルの「出すタイミング」を「フラグが立った日（ずらせる）」にして、フラグと日数を入れる
選んだもので文章を変えるチュートリアルの各ページの「このページを出す条件」（イベントと同じ条件の部品）。満たさないページは飛ばされます
注意　出せるページが1枚も無いときは、出さずに見送ります（「見た」にもしません）。「フラグが立った日」で出すものは、あとで条件を満たした日に出ます。「ストーリーを出す」はその場で1回だけ試すので、日をおいて出したいものは「フラグが立った日」にしてください。

9気をつけること

  • 置き場所：Resources/Events の外に置いたイベントはゲームに出ません（チェックで ⚠）。
  • ID は変えない：イベント ID・選択肢 ID・フラグ ID はセーブの記録に使います。ゲームに出したあとに変えると、前の選択やフラグの条件が合わなくなります。名前（タイトル・ラベル・表示名）は変えてかまいません。
  • 共有の条件：別アセットの条件をほかのイベントも使っていると「ほかでも使っています」と出ます。このイベントだけ変えたいときは［このイベント専用にコピー］。
  • 選択肢・ページを消したとき：そこに付けていた条件も、アセットの中から自動で消えます。
  • 出る順番：月の初めの食事選択が開いている間は、イベントは出ずに待ちます。食事を選んで画面が閉じたあとに出ます（同じ日の固定イベントも同じ）。イベントのダイアログは、ほかの画面（お金表示・カレンダー・食事選択など）より必ず手前に出ます。
  • カードの見た目：選択肢は1〜4つまで。4つのときは1つぶんの幅が半分になるので、ラベルは短めにします（10文字を超えると、編集ウィンドウのチェックで ⚠ が出ます）。画面の比率が横長だと、カードは自動で縮みます。
  • 古いイベント：選択肢 ID が空のイベントは、メニュー「子育て › イベント › 選択肢に ID を付ける」で一度に付けられます。
