# 会社の制度（育休・時短）の設計

> サポート画面の「会社」タブに出す制度（育児休業給付金・出生後休業支援給付金・時短勤務・育児時短就業給付金）の作り方。
> 今までの制度は「決まった額のお金が入る」だけだったが、会社の制度は **親の働き方そのものが変わる**。そのための仕組みを足す。
> 給付率は現実の2025年4月以降の制度（support-systems.md 2章）。期間・数値の細かいところはたたき台。

---

## 0. 決まったこと（2026-10-08）

| 項目 | 決定 |
|---|---|
| 作り方 | **段階的に作る**（第1段階：育休 → 第2段階：出生後休業支援給付金 → 第3段階：時短） |
| 誰が育休を取るか | **プレイヤーが選べる**（母・父・両方） |
| 育休の長さ | **子どもが1歳になるまで**（＝0歳12月31日まで。1歳1月1日に自動で復帰） |
| 育休明けの不利（マミートラック） | **入れない** |
| 時短勤務 | **スライダーを「休み」の1つ手前（ライフ寄り・給料×0.8）に固定**（2026-10-09 案A。一番ライフ寄りは「休み」になったため） |
| スライダーを一番ライフ寄り（0）にしたとき | **休んでいる扱い。給料は入らない**（2026-10-09 決定 → 6章） |
| 出産手当金（産休） | **入れる**（2026-10-09 決定 → 2.5） |
| 育休・時短を途中でやめる | **作る**（2026-10-09 決定 → 2.4） |
| 給付の上限額 | 6章の判断待ち（現実：育児休業給付金 月332,454円が上限・2026年8月〜） |

## 1. 新しく足す仕組み（2つ）

### 1.1 親の「働き方の状態」（WorkMode）

```csharp
public enum WorkMode { Normal, MaternityLeave, ParentalLeave, ShortTime }   // 通常／産休中／育休中／時短中
```

`ParentStatus` に持たせる（Core・山口）。

| 状態 | 会社からの給料（日給） | ワークライフバランス | スライダー |
|---|---|---|---|
| Normal | 今まで通り（月給÷30×バランス倍率） | プレイヤーが動かす | 動かせる |
| ParentalLeave | **0** | **0（一番ライフ寄り）に固定** | 動かせない |
| ShortTime | ×0.8（「休み」の1つ手前に固定） | **ライフ寄り（×0.8 の位置）に固定** | 動かせない |

- バランスを0に固定すると、**親のストレス（`ParentStressSystem`）や子どもとの時間など、バランスを読んでいる仕組みが全部そのまま「ライフ寄り」として動く**。育休・時短のために個別の処理を書かなくてよい。
- 状態を Normal に戻したら、**休む前のバランスに戻す**（`ParentStatus` が覚えておく）。
- 窓口：`SetWorkMode(WorkMode)` ／ `WorkMode`（読み取り）／ `OnWorkModeChanged`。`SetBalance` は Normal 以外では無視する。
- スライダーの UI（親カード）は `OnWorkModeChanged` を見て、Normal 以外では触れないようにし、「育休中」「時短中」と表示する。
- 昇進の仕組みはまだ無い。作るときは「育休中は昇進しない（止まる）」とする。**復帰後の不利は入れない**（決定）。

### 1.2 給料に連動する支給（WageLinkedTier）

育休給付は「休む前の給料の67%」のように、**金額ではなく率**で決まる。支給表（`PaymentTier`）の金額は固定なので、率で払う表を別に持つ。

```csharp
public enum WageBase { SalaryBeforeLeave, CurrentWage }   // 休む前の月給／今の給料

[System.Serializable]
public class WageLinkedTier
{
    public string label;          // 例 "180日まで"
    public int    fromDay = 1;    // 休み始めから何日目から（含む）
    public int    toDay   = -1;   // 何日目まで（含む）。-1 = 終わりまで
    [Range(0f, 1f)] public float rate = 0.67f;   // 率
    public WageBase basis = WageBase.SalaryBeforeLeave;
}
```

- **休む前の月給**＝申請した時点の `MonthlySalary`（役職の月給）。スライダーの位置は使わない（直前にワーク寄りにして給付を増やす、という抜け道を作らないため）。休み始めに `SupportSchemeRuntime` に記録する。
- **日割りで計算し、毎月まとめて払う**：1日分＝月給÷30×率。月が変わったとき（給料日と同じタイミング）に、前の月に休んだ日数ぶんを払う。
- **給付には手取り率（0.8）を掛けない**。現実でも育休給付は非課税で、社会保険料も免除される。だから「額面の67%」でも手取りではおよそ8割になる。これはゲームで学べるポイントなので、家計簿の行に「育児休業給付金（非課税）」と出す。
- 家計簿（expenses.md 5章）には給料とは別の行で載せる。

## 2. 第1段階：育児休業給付金

### 2.1 制度アセットの作り（母と父で1枚ずつ）

「誰が取るか選べる」を、**母用・父用の2枚のカード**で実現する。プレイヤーはどちらか、または両方を申請する。申請画面に選択肢を足すより作りが簡単で、両方取っているかどうかも状態で分かる（第2段階で使う）。

| 項目 | 育児休業（母） | 育児休業（父） |
|---|---|---|
| Id | `parental_leave_mother` | `parental_leave_father` |
| Category | Company | Company |
| Effect Timing | Monthly | Monthly |
| Start | 0歳1月1日 | 0歳1月1日 |
| Deadline Type / Deadline | Once / 0歳12月31日 | Once / 0歳12月31日 |
| Work Mode（新） | 対象：母／ParentalLeave／終わり：0歳12月31日 | 対象：父／ParentalLeave／終わり：0歳12月31日 |
| Wage Linked Tiers（新） | 1〜180日目：67%／181日目〜：50%（休む前の月給） | 同じ |

`SupportScheme` に足す項目：

```csharp
[Header("働き方（会社の制度）")]
public bool       changesWorkMode = false;
public ParentRole workTarget;                 // Mother / Father
public WorkMode   workMode = WorkMode.ParentalLeave;
public GameDay    workModeUntil;              // この日まで（含む）。過ぎたら Normal に戻る
public List<WageLinkedTier> wageLinkedTiers;  // 給料に連動する支給
```

### 2.2 流れ

```
［申請する］（会社タブ・育児休業（母））
   → 母の WorkMode = ParentalLeave（給料 0・バランス 0 に固定）
   → 状態「受給中」。休む前の月給を記録
毎月1日（給料日）
   → 前の月に休んだ日数 × 月給÷30 × 率（180日まで67%、それ以降50%）を払う
0歳12月31日を過ぎる（1歳1月1日）
   → 母の WorkMode = Normal（バランスを元に戻す）
   → 状態「受給終了」
```

- 支給は申請した**翌月の1日から**（前の月の分）。今までの Monthly と同じ「さかのぼらない」考え方。
- カードの期限の行：受給中は「育休中：月○○円（○日目・67%）／1歳1月1日に復帰」。
- 途中で復帰する機能は第1段階では作らない（1歳まで休む）。

### 2.4 途中で復帰する（2026-10-09 決定）

- 受給中の育休カードに **［復帰する］** ボタンを出す（主ボタンが「申請する」の代わりに「復帰する」になる）。
- 押すと確認を出し、OK なら：その親の WorkMode = Normal（バランスを元に戻す）、状態「受給終了」。
- 給付は**休んだ日数ぶんだけ**払う（日割りなので、次の給料日に前の月の休んだ日の分が入る）。
- 一度復帰したら、同じカードでもう一度育休は取れない（現実は2回まで分けて取れるが、第1段階では1回）。
- 時短（第3段階）も同じ［やめる］を付ける。

### 2.5 出産手当金（産休）（2026-10-09 決定：入れる）

現実：出産した母は産後8週間（56日）は働けない（うち6週間は法律で就業禁止）。その間は会社の給料が出ない代わりに、健康保険から **出産手当金（給料の約3分の2）** が出る。申請しないともらえない。

ゲームでは：

| 項目 | 内容 |
|---|---|
| 産後休業（自動） | **母は 0歳1月1日〜0歳2月25日（56日）、自動で休み**（WorkMode = MaternityLeave・給料0・バランス0に固定）。プレイヤーは変えられない |
| 出産手当金（カード） | Category：**Government**（健康保険のため会社タブではない）。対象：母。率：休む前の月給 × **2/3**、日割り。期間：0歳1月1日〜0歳2月25日。申請期限：Once 2歳1月1日（現実：休んだ翌日から2年で時効）。**申請しないともらえない** |
| 支給のタイミング | 申請した翌月の1日に、**それまでに休んだ日の分をまとめて**払う（期限内なら産休が終わってから申請しても全額もらえる＝現実と同じ） |
| 産休のあと | 0歳2月26日から母は通常に戻る。続けて育休（母）を申請すれば、そのまま育休に入れる |

- `WorkMode` に `MaternityLeave` を足す。日給0・バランス0に固定・スライダー不可は育休と同じ。
- 出産手当金も非課税なので手取り率は掛けない。
- 学べること：**出産直後は母の給料が止まる。申請すれば約3分の2が戻る**。

## 3. 第2段階：出生後休業支援給付金

- 現実：子どもが生まれて8週間以内に、**両親とも14日以上**育休を取ると、最初の28日間は給付が13%上乗せされ、手取りがほぼ10割になる。
- ゲーム：
  - 新しい条件の部品 `BothParentsOnLeaveRequirementSO`（`GameContext` の `MotherWorkMode` / `FatherWorkMode` がどちらも ParentalLeave）を作る。
  - 制度アセット「出生後休業支援給付金」（Company／OnApply）：申請条件＝両親とも育休中、期限＝0歳2月26日（生まれてから8週間）。
  - 効果は「両親それぞれの休む前の月給 × 13% × 28日分」を1回で払う。給料連動の **1回払い** になるので、`WageLinkedTier` を OnApply でも使えるようにする（日数＝28日固定）。
- 学べること：**父親も育休を取ると家族全体で得をする**。

## 4. 第3段階：時短勤務・育児時短就業給付金

| 制度 | 作り |
|---|---|
| 時短勤務（母・父で1枚ずつ） | Company／申請すると WorkMode = ShortTime（バランス0に固定・日給×0.8）。終わり：2歳12月31日（現実：3歳まで時短を使える）。お金の効果は無し |
| 育児時短就業給付金 | 時短中の給料（今の給料）× **10%**。**1歳12月31日まで**（現実：子どもが2歳になるまで）。申請条件＝その親が時短中 |

- 時短は「スライダーを一番ライフ寄りにしたのと同じ」（決定）なので、給料・ストレス・子どもとの時間は今の計算がそのまま使える。
- 育休から時短へ続けて使う流れ（1歳で育休明け → 時短）が、現実の典型パターンとして体験できる。

## 6. スライダーの「一番ライフ寄り＝休み」と時短（2026-10-09）

### 6.1 決まったこと

- ワークライフバランスのスライダーを**一番ライフ寄り（0）にしたら「休んでいる」扱い。会社の給料は入らない**。
- 今の `ParentStatus.BalanceMultiplier`（ライフ寄り 0〜20 は ×0.8）を変える：**0 のときだけ ×0**（給料なし）、1〜20 は ×0.8 のまま。
- 制度を申請せずに休むと **お金は何も入らない**。育休・産休を申請して休むと **給付が入る**。この違いが「制度を知っていれば得をする」の学びになる。
- ストレスは今の計算どおり一番下がる（休んでいるので）。

### 6.2 決めること

1. ~~「0」の範囲~~ → **吸い付きは作らない（2026-10-09）**。一番左までドラッグすると値が0になり、日給が **0** と表示されることで休みだと分かる。実装済み（`ParentStatus.BalanceMultiplier`：0.005 未満は ×0）。
2. ~~時短をどう表すか~~ → **案A に決定（2026-10-09）**：時短中はスライダーを **「休み」の1つ手前（ライフ寄り・×0.8）** に固定する。
3. **給付の上限額**：現実の育児休業給付金は、休む前の給料が高くても月332,454円（2026年8月〜・67%の期間）が上限。ゲームの月給は部長で 420,000 円、67% で約28万円なので、**今の給料の範囲では上限に届かない**。入れなくても結果は変わらない。
