# ミニゲーム（半年ごとの30秒ミニゲーム）

> 半年に1回、子どもの年齢に合った30秒のミニゲームが起きる。タブレットのタップ・長押し・スライドで遊べる。
> 数値（制限時間・判定の幅・結果の増減）はすべて **たたき台**。`MiniGameManager` をシーンに置けば Inspector で調整できる。

---

## 1. 流れ

1. 出番の日になると、説明画面（あそびかた・まめちしき）が開く。**この時点から結果を閉じるまで時間を止める**（`GameClock.PushPause` / `PopPause`）。
2. 「スタート」を押すと 3・2・1 のあと 30 秒。
3. 結果は 大成功／成功／失敗 の3段階。**失敗してもゲームオーバーにはならない**（ステータスが悪い方に動くだけ）。

## 2. いつ出るか

- **0歳6月1日が1回目。以降 6か月ごと（毎年 6月1日・12月1日）。** 暦は `GameDate`（生まれた日 = 0歳1月1日）。→ [0032](../decisions/0032-minigame-schedule-june-december.md)
- どれを出すかは **出番表**（`MiniGameManager.schedule`：ミニゲームの種類・何歳から・何歳未満）から、いまの年齢に合うものを **ランダムに1つ**。同じものは2回続けて出さない。
- 出番が来たらその場で時間を止めて「予約」し、ほかの判断画面（食事の選択・イベントなど）が開いていない状態が 0.3 秒（`settleSeconds`、実時間）続いたら出す。食事の選択画面は1フレーム遅れて開くので、**食事を先に選んでもらい、そのあと同じ日のうちに**ミニゲームが出る。
- 倍速（2x・3x）でも同じ。ミニゲームの時間は `Time.timeScale` の影響を受けない（実時間で数える）。
- 何らかの理由でその日の日付の通知を受け取れなくても、同じ月のうちに次の通知が来れば出す（取りこぼさない）。
- ロードで日付が飛んだときは、過去の分はまとめて出さない。
- 出ない場合：年齢に合うミニゲームが出番表に無い（**いまは3歳以上**）、ゲームオーバー後。

## 3. いまあるミニゲーム（0〜3歳未満）

| ミニゲーム | 操作 | 判定（たたき台） |
|---|---|---|
| ミルクの温度合わせ | 蛇口のつまみを左右にスライド（水⇔お湯） | 適温 36〜40℃ に 2 秒入り続けたら完成。残り 12 秒以上で大成功／時間切れで適温なら成功、それ以外は失敗 |
| 寝かしつけ | 縮む輪が水色の輪に重なる瞬間にタップ | 泣き声を下げて「ねんね」を満タンに。残り 8 秒以上で大成功／時間切れは失敗 |
| ミルクを飲ませる | 長押しで飲ませる・離すと休けい | 満腹度は顔だけで判断。にこにこで 2 秒休ませたら完了（むせずに残り 8 秒以上で大成功）／くるしい顔で止めたら成功／吐く・時間切れでお腹がすいたままは失敗 |

まめちしき（説明画面）は公的機関・メーカーの情報を元にした一般的な内容。出典は画面内に記載。

## 4. 結果の反映

- 子どものストレス・体調、親（全員）のストレスを、`PersonStatus.AddStress` / `ChildStatus.AddHealth` の窓口から動かす（特性・状態の補正は窓口で掛かる）。
- 値は各ミニゲームの `Settings.effects`（失敗／成功／大成功ごと）。
- **未対応**：AGENTS.md ルール3の `List<Effect>` ＋ `EffectApplier` にはまだ乗せていない（結果ごとの効果をデータで持つ形にはしてある）。

## 5. 絵

- 絵はすべてドット絵（PPU 20 / Point）。差し替え枠は `Assets/Yamaguchi/Resources/MiniGameArt.asset`。
- 赤ちゃん・部屋は既存の絵を使い、小物（哺乳瓶・温度計・ベビーベッド・顔のアップなど）は家族キャラと同じマス目方式で描いた（`Assets/Images_animation/MiniGame/`）。
- マス目を直したら、メニュー「子育て → ミニゲーム → ドット絵を作り直す」（`MiniGamePixelArtBuilder`）で書き出し直す。

## 6. スクリプト（`Assets/Yamaguchi/Scripts/MiniGame/`）

| ファイル | 役割 |
|---|---|
| `MiniGameManager` | 出番の判定・説明画面・カウントダウン・残り時間・結果・時間停止。シーンに置かなくても再生時に自動で作られる |
| `MiniGame` | ミニゲーム1本の土台（結果を返すだけ。ステータスは触らない） |
| `MilkTemperatureGame` / `SleepRhythmGame` / `MilkFeedingGame` | 各ミニゲーム |
| `MiniGameArt` | ドット絵の差し替え枠（ScriptableObject） |
| `MiniGameUIKit` | UI 部品（TMP＋JPFont・太字、ドット絵は整数倍で表示） |
| `MiniGameTypes` | 結果（Rank）・種類（Kind）・効果の表 |

## 7. デバッグ

- 再生中に F8＝ミルクの温度合わせ、F9＝寝かしつけ、F10＝ミルクを飲ませる。
- 開始するとコンソールに「[MiniGame] 0歳6月1日 に「…」を開始」と出る。
