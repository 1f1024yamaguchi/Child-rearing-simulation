# 食事システム（リアル要素つき）

> 「安い＝Badイベントが起きやすい」を軸に、食事の質を現実の健康影響へ広げた設計。
> [rules-and-stats.md](rules-and-stats.md) セクション4の詳細版。**数値はすべて調整前のたたき台。**
> 根拠：栄養と学力・集中力、栄養バランスと免疫は公的資料でも示されている（末尾の出典）。

---

## 1. グレード別の効果（現在のたたき台）

| グレード | 費用/月 | ストレス（**全員に同じ量**） | イベント発生率 |
|---|---|---|---|
| 最安値 | 30,000 | +5 | Badイベント **+5%** |
| 普通 | 90,000 | −2 | ±0 |
| 高級 | 150,000 | −5 | Goodイベント **+5%** |

- ストレスは母親・父親・子どもがそれぞれ持つが、**食事は家族で同じものを食べるので全員に同じ量を適用する**（人によって増減量を変えない）。→ [../decisions/0005-per-person-stress.md](../decisions/0005-per-person-stress.md)
- 高級の効果は「Badイベントが減る」ではなく「**Goodイベントが増える**」とする。得をする方向に振ったほうが、お金を使う判断が前向きになるため。
- 選択のタイミングは月1回（[rules-and-stats.md](rules-and-stats.md) 1章の月次処理）。
- **選択画面を開いている間はゲーム内時間を止める**（[../decisions/0004-pause-during-decisions.md](../decisions/0004-pause-during-decisions.md)）。
- 費用が収入に対して重いのは意図的。安易に高級を選び続けられないほうが判断が生まれる。

### 効果の持ち方（重要）

**この表の数値をコードに直接書かないこと。** グレードは `List<Effect>` を持つデータとして定義し、適用は共通の `EffectApplier` に任せる。→ [effects.md](effects.md)

```
最安値 : [ Stress +5 → Everyone, Money -30000, BadEventRate +5% (ThisMonth) ]
普通   : [ Stress -2 → Everyone, Money -90000 ]
高級   : [ Stress -5 → Everyone, Money -150000, GoodEventRate +5% (ThisMonth) ]
```

こうしておけば、下の2章・3章にある「体調」「成績」「虫歯」といった効果を**後から足すときに、食事側のコードを触らずに済む**。数値も効果の種類も今後変わる前提なので、ここは必ず守ること。

## 2. 安い（質が低い）食事で起きやすいこと（リアル要素）

> 以下は**今後 Effect として足していく候補**。1章の表にはまだ入っていない。優先順位をつけて少しずつ足す。

1. **免疫が下がる → 風邪・感染症にかかりやすい**（体調↓、Badイベント率↑）。栄養バランスの乱れは免疫低下につながる。
2. **虫歯・肥満のリスク**（安い食事は糖質・脂質・インスタントに偏りがち）→ 虫歯イベント、体調−。
3. **集中力・成績が伸びにくい**（栄養不足・朝食欠食）。朝食欠食と学力・集中力の低下には相関が示されている → 成績にマイナス補正。
4. **子どものイライラ・ストレス↑**（血糖の乱高下、満足感の低さ）→ 子ストレス+、家出リスクにも波及。
5. **発育がゆっくり**（身長・体格）→ スポーツ趣味に不利、などの長期影響。
6. **生活習慣病の芽**（長期）→ 大人になってからの体調・エンディング演出に反映。

## 3. 高い（質が良い）食事で起きるいいこと（リアル要素）

> こちらも**今後足す候補**。

1. **免疫が上がる → 病気しにくい**（体調安定、Badイベント率↓）。
2. **集中力アップ → 成績にプラス補正**（しっかりした食事・朝ごはん）。
3. **ストレス↓・機嫌↑**（美味しい食事の満足感、食卓での家族団らん）→ 親子ともに効く。
4. **発育が良好** → good状態（絶好調）が出やすい、スポーツ趣味に有利。
5. **「食育」イベントのきっかけ**：子が食・料理に興味 → 新しい趣味（料理）を発見。
6. **まれに家族団らんボーナス**：親のストレスも大きく下がる。

## 4. バランス設計のねらい

- **毎月「高級」である必要はない設計にする**のがミソ。高級は家計を圧迫（貯金が減り、他の支援・イベントに回せない）。
- 基本は「普通」で回し、ストレスや体調が悪化した月だけ「高級」で立て直す、という**メリハリの判断**が生まれる。
- 最安値は短期的にお金は浮くが、Badイベント率↑・成績↓・子ストレス↑がじわじわ効いて、結局あとで高くつく（＝リアル）。
- → 「今お金を節約するか、将来の体調・成績・心の余裕に投資するか」というトレードオフ。
