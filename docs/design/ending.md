# 進路と巣立ちエンディング

> ゲームの終わり方を「20歳でクリア」から **「子どもが親元を離れたら終了（巣立ち）」** に変える。
> 高校卒業で進路が分かれ、**進路によって巣立つ年齢（＝プレイの長さ）が変わる**。
> 巣立ちの瞬間に **子どもが何の職業になったか** をリザルトで流す。
> 数値・職業名はすべて **調整前のたたき台**。

## 0. 決まったこと

| 失敗 | 家出＝ゲームオーバー（child-status.md 4章のまま）。巣立ちより先に来たら家出エンディング |
| リザルト | 職業／巣立ちの年齢／稼いだお金／子育てにかかったお金 などを流す |

| 大学に落ちたとき | **浪人／就職／専門** から選ぶ。大学を希望していた子に浪人以外を選ぶとストレス。浪人はお金がかかる（2026-10-16 決定） |
| 入れないもの | **中退**、**高校の種類**（普通科／専門学科）の選択（2026-10-16 決定） |
| 奨学金・修学支援 | **実際の制度の金額・条件に合わせる**（2026-10-16 決定。3.3） |

| 奨学金・修学支援の再現範囲 | 大学は **私立の値に統一**（国公立と分けない）／**自宅通学のみ**／貸与型は **サポート画面の申請ダイアログで月額を選ぶ**。借りた額は **リザルトに表示するだけ**（2026-10-19 決定。3.3） |

| セーブ＆ロードでの合否のやり直し | **許す**。合否の乱数はセーブに入れず、2月の抽選のたびに引く（2026-10-16 決定） |

## 1. 全体の流れ

```
誕生 ─── 小・中・高 ─── 高3の7月：進路を決める ─── 高3の2月：合否 ─── 3月：高校卒業
                                                          │
                                              不合格 → 浪人／就職／専門 を選び直す
                                              （浪人なら翌年2月に再受験。巣立ちが1年延びる）
                                                                          │
     ┌────────────────────┬──────────────────────┬────────────────────────┘
     ▼                    ▼                      ▼
  就職（高卒）          専門学校（2年）           大学（4年）
  18歳3月末で巣立ち     20歳3月末で巣立ち         22歳3月末で巣立ち（浪人1年なら23歳）
     │                    │                      │
     └──────────┬─────────┴──────────────────────┘
                ▼
        職業の判定 → リザルト → 育成記録に保存

※ どの時点でも、家出の条件を満たしたら家出エンディング（ゲームオーバー）
```

### 時期は「年齢」ではなく「学年と月」で決める

年齢の起点は **0歳1月1日**（support-apply.md・expenses.md と同じ）で、学年は **4月始まり**（expenses.md：高校は 15歳4月〜18歳3月）。
「18歳になった日」で区切ると1月になり、卒業（3月）とずれる。
進路・巣立ちのイベントは **学年と月** で発火させる（月はカレンダー月 → decisions/0009）。

| 区切り | 学年 | ゲーム内の日付 |
|---|---|---|
| 高校受験の合否 | 中3 | 15歳2月 |
| 進路を決める | 高3 | 17歳7月 |
| 推薦の合否 | 高3 | 17歳11〜12月 |
| 一般入試の合否 | 高3 | 18歳2月 |
| 高卒の巣立ち | 高3 | 18歳3月31日 |
| 専門卒の巣立ち | 専門2年 | 20歳3月31日 |
| 大卒の巣立ち | 大学4年 | 22歳3月31日（浪人1年なら 23歳3月31日） |

> 1日＝1秒なので、大学ルートは高卒ルートより **約24分長い**（4年＝1460秒）。

## 2. 進路の種類

| 進路 | 在学 | 主な条件（たたき台） | ゲーム上の特徴 |
|---|---|---|---|
| 就職（高卒） | なし | なし（いつでも選べる） | 一番早く巣立つ。学費ゼロ |
| 専門学校 | 2年 | 専門の合格ライン以上（低め）＋入学金＋初年度の学費を払える | 趣味の種類で分野が決まる（料理・美容・音楽・ゲーム…） |
| 大学 | 4年 | 大学の合格ライン以上（高め）＋入学金＋初年度を払える | 学費が一番重い。職業の選択肢が一番広い |
| スポーツ・芸術の推薦 | 進路による | 趣味Lv が一定以上 ＋ **評定が出願基準以上** | 一般入試より低い成績で大学に進める。ただし成績がまったく無いと出願できない |

**入れないと決めたもの**：中退、高校の種類（普通科／専門学科）の選択。
**今は入れないもの（10章で検討）**：短大、大学院を実際にプレイすること。

## 2.5 テストと受験の時期（決定）

1日＝1秒なので **1年は約6分**。現実どおり年5回テストをすると約70秒ごとに来て判断画面だらけになるため、
**時間を止める判断** と **自動で流れる判定** を分ける。

| 時期 | 内容 | 時間を止める？ | 効果 |
|---|---|---|---|
| 小学校 7・12・3月 | **通知表**：その時点の成績を見せるだけ | 止めない | なし（判定しない） |
| 中学・高校 7・12・3月 | **学期末テスト**：合格ライン（`passLine`、既定60）で自動判定 | 止めない（通知だけ） | 下回ったら 子ストレス＋、記録に残す |
| 中3の2月 | **高校受験**：公立に受かるか | 止める | 落ちたら私立高校（学費が変わる） |
| 高3の7月 | 進路を決める | 止める | 3章 |
| 高3の11〜12月 | 推薦の合否 | 止める | 3.4 |
| 高3の2月 | 一般入試の合否 | 止める | 3.4 |

- 判定はすべて **画面に出ている成績（丸めた整数）** で行う（child-status.md 5章）
- 学期末テストは中1〜高3で **18回**

### 高校受験（公立か私立か）

- 高校の種類は選ばせないが、**公立か私立か** はお金の差として効かせる
- 合否は 3.5 と同じ確率の式（公立高校用の `PathDefinition` を1つ持つ）。不合格なら私立
- 高等学校等就学支援金（2026年度〜、所得制限なし）：公立は年 118,800円、私立は上限 年 457,200円。**入学金・制服代などは対象外**で自己負担
  → 私立になっても支援を申請すれば授業料はほぼまかなえるが、初期費用は重い（申請しないと0円）
- 公立を望んでいたのに私立になったら 子ストレス＋（小さめ）
- 金額は support-apply.md の高校就学支援金（月 9,900円まで）を **2026年度の制度に合わせて更新すること**（私立の上限が抜けている）

### 評定

- **高校の学期末テスト（高1〜高3、計9回）の平均** から評定（5段階）を出す
- 評定は推薦・修学支援（評定平均 3.5以上）・無利子奨学金（同）の条件に使う
- 成績→5段階の換算（たたき台）：0–19＝1／20–39＝2／40–59＝3／60–79＝4／80–100＝5

> child-status.md 5章（「テストの時期は未定」）を本章への参照に書き換えること。

## 3. 進路を決める（高3の7月）

### 3.1 誰が決めるか

**親（プレイヤー）が選ぶ。ただし子どもの希望が表示される。**

- 時間を止めて「進路を決める」画面を出す（他の判断画面と同じ順番待ち。support-apply.md のリマインダーと同じ仕組み）
- 進路ごとに **選べる／選べない（理由つき）** を表示する
- 子どもの **希望** を1つ表示する（趣味・成績から決まる。例：スポーツLvが高い → 「スポーツを続けたい」）
- 希望と違う進路を選ぶと **子ストレス＋30**（最大100の3割。たたき台。`PathDefinition` ではなく進路決定の設定値として1か所に持つ）。「親が決めた進路」の記録も残し、職業判定とリザルトに使う

> 「親が子の進路を決めつけるか、子の希望を聞くか」のジレンマ。巣立ち直前でも家出は起きうるので軽くはない。

### 3.2 選べるかどうかの判定

条件は **`RequirementSO` / `GameContext`（支援・支出と共用）** で書く。進路ごとに条件を並べるだけにする。

| 判定に使う値 | どこから | 使い道 |
|---|---|---|
| 成績（丸めた整数） | ChildStatus.Grade | 大学の合否 |
| 学期末テストで合格ラインを下回った回数 | ChildStatus（child-status.md 5章） | 職業判定の条件（回数が多いと研究職などが外れる）。**受験の不合格は含めない** |
| 趣味の種類と Lv | ChildStatus.Hobby / HobbyLevel | 推薦・専門の分野・職業 |
| 貯金 | GameState.Money | 入学金＋初年度を払えるか |
| 年収 | IncomeHistory | 修学支援（授業料減免・給付型奨学金）の対象か |
| 特性 | PersonStatus.Traits | 職業の加点（「勉強が得意」→ 研究職 など） |

### 3.3 お金が足りないとき

払えない進路は **そのままでは選べない**。ただし次で選べるようにする（＝制度を知っていれば道が開く）。
**金額・条件は実際の制度に合わせる。** 以下は 2026年度の制度で確認できた値。

#### ゲームでの再現範囲（2026-10-19 決定）

- 大学は国公立／私立に分けず、**私立の値** を使う
- 通学は **自宅通学のみ**（自宅外通学は入れない。大学で家を出る＝巣立ち、と矛盾させないため）
- 貸与型奨学金は **プレイヤーが月額を選ぶ**
- 家族は子1人なので、多子世帯の枠は使わない

#### 修学支援新制度（授業料等減免＋給付型奨学金・返還不要）

- 対象：住民税非課税世帯とそれに準ずる世帯（第Ⅰ〜Ⅲ区分）
- 学力の条件（入学時）：高校の **評定平均 3.5以上**、または学修意欲を学修計画書で確認
  → ゲームでは高校の「評定」で判定する（評定の出し方は 2.5章）。学修計画書の道は入れない（たたき台）
- 毎年、成績と世帯収入が基準を満たしているか確認される（＝在学中も条件が切れうる）

**授業料等減免の上限（私立・年額。第Ⅰ区分）**

| 進路 | 入学金 | 授業料 |
|---|---|---|
| 大学 | 約 260,000円 | 約 700,000円 |
| 専門学校 | 約 160,000円 | 約 590,000円 |

第Ⅱ区分はこの 2/3、第Ⅲ区分は 1/3。

**給付型奨学金（私立・自宅通学・月額）**

| 区分 | 月額 |
|---|---|
| 第Ⅰ区分 | 38,300円 |
| 第Ⅱ区分 | 25,600円 |
| 第Ⅲ区分 | 12,800円 |

- 区分を決める年収は IncomeHistory から。**区分の境目の年収は要確認**（家族構成で変わる）
- ゲーム上の作り：授業料等減免は学費の `ExpenseItem` を `covers` で肩代わり（support-apply.md 9.2 と同じ形）、給付型奨学金は毎月お金をもらう制度（Monthly）

#### 貸与型奨学金（JASSO・卒業後に返還）

**サポート画面の制度として申請し、申請ダイアログで月額を選ぶ（2026-10-19 決定）。**
進路決定の画面とは別にせず、児童手当などと同じ **サポート画面（政府タブ）のカード** にする。

| カード | 申請できる期間 | ダイアログで選ぶもの |
|---|---|---|
| 貸与型奨学金（第一種・無利子） | 大学・専門の在学中（条件を満たすとき） | 月額（4段から1つ） |
| 貸与型奨学金（第二種・有利子） | 大学・専門の在学中 | 月額（2万〜12万円）／入学時特別増額（なし・10万〜50万円。1年生の4月だけ） |

| 種類 | 選べる月額（私立・自宅通学） | 条件 |
|---|---|---|
| 第一種（無利子） | 大学：20,000／30,000／40,000／54,000円　専門：20,000／30,000／40,000／53,000円 | 評定平均 3.5以上 ＋ 家計基準。家計収入が一定以上だと最高月額は選べない |
| 第二種（有利子） | 20,000〜120,000円（10,000円単位） | 第一種より緩い |
| 入学時特別増額（有利子） | 100,000〜500,000円（100,000円単位）・1回 | 第二種と一緒に借りる（ゲームでは第二種のダイアログで選ぶ） |

#### 申請ダイアログ（support-apply.md 7.3 の拡張）

いまの確認ダイアログ（もらえるもの／注意／［やめる］［申請する］）に、**金額を選ぶ欄** と **返済の注意** を足す。

```
貸与型奨学金（第二種）を申請しますか？
          （来月から）

  借りる金額（毎月）
    [−]   50,000円   [＋]          ← 1万円単位。第一種は4つのボタンから選ぶ
  入学時に追加で借りる
    [なし][10万][20万][30万][40万][50万]   ← 1年生の4月だけ表示

  もらえるもの
    毎月 お金 +50,000

  注意
    卒業後に返さなくてはいけないお金です（借金）
    卒業までに借りる合計：約 2,400,000円     ← 月額 × 残りの在学月数 ＋ 増額。選ぶたびに更新

        [やめる]  [申請する]
```

- 注意欄の「返さなくてはいけない」は **赤字で必ず出す**。給付型（返さなくてよい）との違いが学べるところ
- 「卒業までに借りる合計」は、選んだ月額と残りの在学月数から計算して、金額を変えるたびに更新する
- 申請すると翌月から毎月 お金 ＋月額（Monthly）。入学時特別増額は申請した時点で1回 ＋
- 借りた額は `LoanTotal`（累計）として持ち、セーブに入れる
- 金額を選ぶ欄は、制度のデータ（`SupportScheme`）に「選べる金額の一覧」を持たせて、ダイアログが自動で出す形にする。金額を選ばない制度（児童手当など）はいままでどおりの見た目

#### 申請した後の変更・やめる（2026-10-19 決定）

現実の JASSO では在学中に月額の増額・減額と辞退ができる（反映まで2〜3か月かかり、短期間に繰り返さないよう求められる）。これに合わせる。

- 申請済みの奨学金カードに **［金額を変える］［借りるのをやめる］** のボタンを置く
- **［金額を変える］**：申請時と同じダイアログで月額を選び直す
  - 新しい月額は **2か月後の月から** 反映する（現実の「2〜3か月」に合わせる。たたき台）。反映を待っている間、カードに「○月から 月○○円に変更」と出す
  - 変更は **1年に1回まで**（4月〜翌3月で数える。たたき台）。使ったらボタンを押せなくし、理由を出す
- **［借りるのをやめる］**：確認ダイアログ（「やめると来月から振り込みが止まります。もう一度借りるには申請し直しが必要です」）を出す
  - **翌月から** 振り込みが止まる。カードは申請前の状態（申請できる）に戻る
  - それまでに借りた分は `LoanTotal` に残り、リザルトの合計に含まれる
- 入学時特別増額は1回きりなので、変更・やめるの対象外
- 待っている変更（いつから・いくら）と、その年度に変更したかはセーブに入れる

#### 借りたお金の扱い

- **返済はゲームでは扱わない。** 子どもが巣立った時点でゲームが終わるため
- リザルトの数字のまとめに **「奨学金（借りたお金）：○○円」** と表示するだけ。利息も入れない

#### まだ確認が要るもの

- 修学支援の区分の境目の年収（父・母・子1人の世帯で）
- 第一種の家計基準と、最高月額が選べなくなる年収
- 併給調整の具体的な額

> 出典：文部科学省「高等教育の修学支援新制度」、日本学生支援機構、各大学の2026年度募集要項。実装前に一次資料で確認する。

### 3.4 合否（高3の2月）

- 大学は2月に合否を出す。判定は **画面に出ている成績（丸めた整数）** で行う（child-status.md 5章と同じ理由）
- 不合格なら **浪人／就職／専門** を選ぶ画面を出す

#### 合格ラインは進路ごとに持つ（決定）

ライン1本で大学も専門も判定すると、専門学校が「大学と同じくらい難しくて、職業の選択肢が少ない進路」になり、選ぶ理由がなくなる。
現実でも専門学校は書類・面接中心で入りやすいところが多い。そこで **進路ごとにラインを持つ**。

| 進路 | 合格ライン（たたき台） | 見るもの |
|---|---|---|
| 大学（一般） | 成績 65 | 成績 |
| 専門学校 | 成績 40 | 成績 |
| 推薦（スポーツ・芸術） | 出願条件：趣味Lv 一定以上 ＋ **評定 3.0以上**（決定・たたき台。成績平均40以上で届く）　／　合否：成績 50 | 趣味の種類とLv、評定、成績 |
| 就職（高卒） | なし | — |

- ラインは `PathDefinition` の項目として持ち、Inspector から変えられるようにする
- 定期テスト用の合格ライン（`ChildStatus.passLine`、既定60）とは **別の値**。混ぜない
- あとで大学を国公立／私立に分ける（国公立＝学費安・ライン高、私立＝学費高・ライン低）ときも、`PathDefinition` を1つ増やすだけで済む形にしておく

### 3.5 合格率と判定（決定：確率）

ラインちょうどで合否が決まると、プレイヤーは結果を事前に分かってしまい、「挑戦させるか、確実な道にするか」の緊張が生まれない。
そこで **ラインとの差から合格率を出し、その確率で合否を決める**。

```
差     = 成績（丸めた整数） − その進路の合格ライン
合格率 = Clamp( 基準 + 差 × 傾き , 下限 , 上限 )
```

| 値 | たたき台 | 意味 |
|---|---|---|
| 基準 | 50% | ラインちょうどのときの合格率 |
| 傾き | 4% / 1点 | ラインから1点離れるごとに変わる量 |
| 下限 | 5% | どれだけ足りなくても残る可能性 |
| 上限 | 95% | どれだけ上回っても残る不安 |

例（大学・ライン65）：成績 75 → 90%　／　成績 65 → 50%　／　成績 55 → 10%

- 4つとも `PathDefinition` に持たせ、Inspector から変えられるようにする（進路ごとに違ってよい）
- **確実な判定に戻したいとき**は、傾きを大きく（例：100%/1点）し、下限0%・上限100% にするだけでよい。仕組みは変えない
- 推薦は「趣味Lv が条件を満たすか」を先に見て、満たしていれば成績で同じ式を使う

#### 模試の判定（A〜E）

合格率をそのまま数字で見せず、模試のような判定で見せる。

| 判定 | 合格率 |
|---|---|
| A | 80% 以上 |
| B | 60〜79% |
| C | 40〜59% |
| D | 20〜39% |
| E | 20% 未満 |

- 7月の進路を決める画面で、進路ごとに判定を出す
- 7月〜2月のあいだも成績は動くので、子カードのステータス欄に「志望：大学 B判定」の行を出して毎月更新する
- 合否は **2月の時点の成績** で計算した合格率で抽選する（7月の判定は目安）
- 判定の境目は表示用。抽選は合格率そのもので行う

| 選択 | お金 | 子ストレス（大学を希望していた場合） | 巣立ち |
|---|---|---|---|
| 浪人 | 予備校代などがかかる | 小（本人の希望どおり。ただし浪人中の重圧はある） | 1年延びる。翌年2月に再受験。**何年でも浪人できる** |
| 就職 | かからない | ＋30（希望と違う） | 高卒と同じ |
| 専門 | 学費がかかる | ＋30（希望と違う） | 専門卒と同じ |

- 子が大学を希望していなかったのに大学を受けて落ちた場合は、就職・専門を選んでもストレスは増えない
- 浪人は **何年でもできる**（上限なし）。年数が増えるほど巣立ちが遅れ、予備校代がかさむ

## 4. 在学中（専門・大学）

- **時間はそのまま進む。** 家出判定・食事・イベントもそのまま
- 支出：学費が毎月かかる（expenses.md の `ExpenseItem` に **進路の段** を足す。年齢の段と同じ考え方）
- 子のステータス：成績・趣味はこれまでどおり伸びる。勉強⇔遊びスライダーも使える
- 児童手当など **年齢で終わる制度** は、在学中でも年齢どおりに終わる（現実どおり）
- 子カードの年齢表示は「19歳・大学1年」のように学年も出す

### 留年（2026-10-19 決定）

- 在学中も学期末テスト（7・12・3月）を続け、学年ごとに成績を判定する
- **3月の時点で、その学年のテストの平均が在学中の合格ラインを下回っていたら留年**
  - 留年すると同じ学年をもう1年。**巣立ちが1年延び、学費が1年分増える**
  - 子ストレス＋（量はたたき台）
- 中退はないので、留年は何回でもありうる（浪人と同じく上限なし）
- 在学中の合格ラインは `PathDefinition` に持つ（たたき台：大学 40／専門 40）。受験・高校の学期末テストの合格ラインとは別の値
- 留年した記録はリザルトの「進路のあゆみ」に出す（例：「大学を5年で卒業」）

## 5. 職業の判定（巣立ちの日）

### 5.1 仕組み

**進路ごとに職業の候補表を持ち、条件を満たす候補のうち点数が一番高いものになる。**
条件を満たす候補が1つもなければ、その進路の **既定の職業** になる。

```
候補ごとに：
  条件（RequirementSO）を満たすか → 満たさなければ除外
  点数 = 成績×a + 趣味Lv×b（趣味の種類が合うときだけ）+ 体調×c + 特性の加点
最高点の候補 → 職業
```

`a`〜`c` は職業ごとに持つ（研究者は成績重視、選手は趣味重視、のように）。

**条件に使う記録は2つに分ける（2026-10-19 決定）。**

| 記録 | 中身 | 使い道 |
|---|---|---|
| 学期末テストの記録 | 学年・学期・成績（中1〜高3の18回＋在学中） | 評定・不合格回数を **ここから計算**。不合格回数は職業判定の条件に使う |
| 受験の記録 | 種類（高校／推薦／一般）・年・志望だったか・判定・合否 | **リザルトとエピローグにだけ使う**。職業判定には使わない |

- 受験に落ちた代償は、その場で進路・学費・巣立ちの年齢が変わることで払っている。職業判定で重ねて減点しない
- 浪人して合格した子は「一度は落ちたが、浪人して第一志望へ」のように物語として語る

**子ストレスは点数に入れない**（2026-10-16 見直し）。理由：
- ストレスはすでに家出（ゲームオーバー）で罰を受けているので、二重の罰になる
- 勉強寄りにするとストレスが上がる仕様なので、成績重視の職業ほど不利になってしまう
- 巣立ちの「その日の値」で決まるため、最後の1か月だけ遊び寄りにすれば点が戻る（ずっと頑張った意味が薄れる）

心の状態を結果に出したい場合は、職業ではなく **エピローグの一言** に使う（例：限界にいた日数が多い →「実家にはあまり帰ってこない」）。

### 5.2 職業の候補（たたき台）

| 進路 | 職業の例 | 主に見るもの |
|---|---|---|
| 就職（高卒） | 職人・工場スタッフ・公務員（高卒）・実業団選手 | 体調・趣味（スポーツ） |
| 専門学校 | 調理師・美容師・ゲームクリエイター・ミュージシャン・保育士 | 趣味の種類とLv |
| 大学 | 会社員・教員・エンジニア・研究者の卵（大学院へ） | 成績・特性 |
| 推薦 | プロスポーツ選手・アーティスト | 趣味Lv |
| どれも伸びなかった | フリーター・模索中 | （既定の職業） |

- **研究者・博士は「大学院へ進学」として巣立ち、エピローグで「○年後、博士に」と見せる**（実際にはプレイしない）
- 職業名・候補は増やしてよい。`CareerDefinition` のアセットを1つ足すだけで増える形にする

### 5.3 将来の夢（2026-10-18 決定）

子どもが「この職業を目指したい！」と言うイベントで、**プレイヤーが育てる方向の目安を知れる**ようにする。

- **中学1年で1回**、「○○になりたい！」のイベントが起きる（2026-10-19 決定。時期は中1の何月かはたたき台：4月）
- 夢の決め方：その時点のステータスで `CareerJudge` を回し、**点数が一番高い職業** にする（進路で絞る前の全職業が対象。ランダムにはしない）
- 夢は中1で決まったら変わらない（変わるイベントを足すかは後で考える）
- 子カードのステータス欄に「将来の夢　○○」の行を出す
- 夢と7月の進路の希望はつながる（夢が調理師 → 希望は専門学校）

**職業の条件・点数はプレイヤーに見せない（決定）。**
- 夢は「名前」だけを出す。条件のチェックリストや「あと少し」のような目安も出さない
- 何をすれば近づくかは、プレイヤーが職業名から想像して育てる

**リザルトでは「○○になった」とだけ出す（決定）。**
- 夢が叶った／叶わなかったという言い方はしない（叶わなかったと出ると寂しいため）
- 夢と違う職業になっても、その職業を前向きに紹介するだけ

> 夢が生まれるイベント自体は丸山さんの担当範囲。夢を決める・持つ・表示する仕組みは Core（山口）が持ち、イベントから呼ぶ形にする。

### 5.4 家出エンディング

家出したら職業の判定はしない。リザルトは「家出」の専用画面にし、育成記録には **家出の有無** と **その時の年齢** を残す。

2. 職業を判定
3. リザルトを流す
4. 育成記録に保存 → タイトルへ

**終了処理は一度きり**（家出と同じくフラグで止める）。巣立ちの日と家出が同じ日に来た場合は **家出を優先** する（たたき台）。

## 8. データとクラス（機能ごとに分ける）

| 名前 | 種類 | 役割 |
|---|---|---|
| `PathDefinition` | ScriptableObject | 進路1つ。在学年数・**合格ライン**・入学条件（RequirementSO）・学費の ExpenseItem・候補の職業リスト |
| `CareerDefinition` | ScriptableObject | 職業1つ。表示名・イラスト・条件・点数の重み・エピローグ文 |
| `ChildPath` | データ | いまの進路・決めた日・「親が決めたか」・合否の記録。ChildStatus が持つ |
| `PathDecisionSystem` | MonoBehaviour | 高3の7月／2月に判断画面を出し、進路を確定する |
| `GraduationWatcher` | MonoBehaviour | 巣立ちの日を監視し、来たら終了処理を1回だけ始める（RunawayWatcher と対） |
| `CareerJudge` | 純粋なクラス | 職業の判定だけ。画面もセーブも触らない（単体で確認しやすく） |
| `EndingResult` | データ | リザルトに出す値の入れ物。育成記録の保存にもそのまま使う |
| `ResultScreenUI` | UI | EndingResult を流して表示するだけ。計算しない |

**判定の計算は `CareerJudge` に1箇所**。UI・セーブ・進路選択の画面は判定の中身を知らなくていい。
