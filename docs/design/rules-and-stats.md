# 基本ルール & ステータス・数値設計

> [concept.md](concept.md) の「検討ポイント」に対する設計案。

## 1. 基本ルール

### 時間の流れ（リアルタイム進行）
- **1秒 = ゲーム内1日**でリアルタイムに進む（ターン制ではない）。→ 経緯は [../decisions/0001-realtime-time-model.md](../decisions/0001-realtime-time-model.md)
- **1ヶ月は実際の暦の日数（28〜31日、うるう年なし）、1年 = 365日**。→ [../decisions/0009-real-calendar-months.md](../decisions/0009-real-calendar-months.md)
- **ゴールは「子どもが巣立った日」で、進路によって変わる**（高卒 18歳3月末／専門卒 20歳3月末／大卒 22歳3月末）。→ [ending.md](ending.md)・[../decisions/0020-ending-on-leaving-home.md](../decisions/0020-ending-on-leaving-home.md)
  - 実装の `GoalAgeDays` は既定値 7300（＝20歳）のまま。進路決定で変わるようにする改修は未着手（[ending.md](ending.md) 6章）。
- 画面下部の年齢バーは `AgeDays ÷ GoalAgeDays` の進捗。満タン＝巣立ち＝エンディング。
- 意思決定のタイミング：
  - **バランススライダー（親＝ライフ⇔ワーク／子＝勉強⇔遊び）は、いつでもリアルタイムに調整**できる。
  - **食事の選択・給料の精算・月初イベントは、月が変わるたび（28〜31日ごと＝実時間28〜31秒ごと）に発生**。
- ※ 1日＝1秒だと、高卒の巣立ち（18歳3月末）まで約6660秒（約1時間50分）、大卒（22歳3月末）まで約8120秒（約2時間15分）。テンポは速度設定でチューニングの余地あり（**未決定**）。

### ゴール：巣立ちのエンディング（＝「何になったか」）
- **2026-10-19 変更**：「20歳でエンディング」から「子どもが親元を離れたら（巣立ち）エンディング」に変えた。→ [../decisions/0020-ending-on-leaving-home.md](../decisions/0020-ending-on-leaving-home.md)
- 高3の7月に進路（就職／専門学校／大学／推薦）を決め、進路ごとに巣立つ年齢が変わる。大学なら 22歳3月末まで実際にプレイし、学費も払い続ける。
- 巣立ちの日に **その子が何の職業になったか** を判定し、リザルトで「○○になった」と流す。
- 進路・受験・職業の判定・リザルトの詳細は [ending.md](ending.md)。
- 世帯の状態（貯金・子育てにかかったお金・受け取った支援）はリザルトの数字のまとめに出す。
- → メリット/デメリットのイベントが「どの職業に向かうか」に効くので、両方が意味を持つ。

### 失敗条件：家出でゲームオーバー
- **子ども自身のストレスが限界（最大）の状態が一定期間続くと、家出してしまい → ゲームオーバー**（巣立ちを待たずに終了）。
  - ※「一定期間」が何日かは **未決定**。判定自体も未実装（`IsGameOver` は `GoalAgeDays` 到達でしか立たない）。
- 巣立ち（エンディング）と家出（ゲームオーバー）が、成功と失敗の対になる。
- → 子どものストレスを常に気にかける必要があり、子カードにも**ストレスメーター**を表示する。

### 子どものストレスの増減（家出を左右する最重要ステータス）
| ストレスが上がる要因 | ストレスが下がる要因 |
|---|---|
| 親がワーク寄りで一緒の時間が少ない（放置） | 親がライフ寄りで一緒に過ごす |
| 安い食事が続く | 良い食事（普通〜高級） |
| 体調不良・風邪などのデメリットイベント | 趣味・遊び・楽しいイベント |
| 親のストレスが高い（ピリピリした家庭環境） | 自治体の子育て支援・レジャー |
| 勉強のさせすぎ（勉強寄りに振りすぎ）／叱りすぎ | 成績・趣味の成功体験 |

### その他のソフトな失敗（ゲームオーバーではなく悪い方向へ）
- 親のストレスが最大で高止まり → 燃え尽き。収入激減 or 休職イベント（→ 家庭環境が悪化し子のストレスにも波及）。
- お金がマイナス継続 → 生活が回らず、子のステータスが下がりやすくなる。
- 子の体調が長期低下 → bad エンディングに寄る。

### 1ヶ月ごとの処理（月が変わるたび = 実時間28〜31秒ごと）
リアルタイムで時間が進む一方、以下は「月が変わったタイミング」でまとめて処理する：

1. **月初イベント**：メリット/デメリットが確率で発生（[events.md](events.md) 参照）。
2. **食事の選択**：最安値 / 普通 / 高級（[food-system.md](food-system.md) 参照）。
3. **収支精算**：給料 − 支出（食事・医療・イベント費）。
4. **ステータス更新**：各人のストレス・成績・趣味・体調・地位を計算。

※ バランススライダーは月をまたがずリアルタイムに調整でき、その設定値が毎月の計算に反映される。
※ 月替わりの通知（`MonthTicker.OnMonthChanged`）と給料日の精算は**実装済み**。イベント抽選・食事選択・ステータス更新は未実装。→ [../code/architecture.md](../code/architecture.md)

## 2. ステータス設計

| ステータス | 対象 | 範囲 | 意味・効果 |
|---|---|---|---|
| ライフ⇔ワーク | 親 | 0–100 | スライダー。ワーク寄り＝月給・地位↑・ストレス↑／ライフ寄り＝子との時間↑ |
| 勉強⇔遊び | 子 | 0–100 | スライダー。勉強寄り＝成績↑・ストレス↑／遊び寄り＝趣味↑・ストレス↓ |
| ストレス値（親） | 母親・父親それぞれ | 0–100 | 高止まりで燃え尽き（収入減・休職）。家庭環境として子に波及 |
| ストレス値（子） | 子 | 0–100 | **限界が続くと家出＝ゲームオーバー**。最重要 |
| 月給 | 親 | 金額 | ワークライフバランス×地位で決まる |
| 地位・役職 | 親 | 段階 | 平社員→主任→係長→課長→部長。上がると月給ベース増 |
| お金（貯金） | 世帯 | 金額 | 給料でプラス、支出でマイナス |
| 成績 | 子 | 0–100 | 勉強⇔遊び・学習アプリ・親との時間で上下。受験の合否と職業（研究者・エンジニアなど）に直結 |
| 趣味 | 子 | 種類＋熟練度 | スポーツ/音楽など。推薦と職業（選手・ミュージシャンなど）に直結 |
| 体調 | 親子 | 0–100 | 風邪などで低下、食事・医療で回復 |
| good/bad状態 | 親子 | フラグ | 一時的な好調/不調（例：風邪、絶好調） |
| 年齢 | 子 | 0歳〜巣立ち（進路で 18〜23歳） | 巣立ちでエンディング。下部バーで進捗表示 |

**ストレスは人ごとに持つ**（母親・父親・子ども）。ただし**食事のように全員が等しく受ける効果は、全員に同じ量を適用する**。→ [../decisions/0005-per-person-stress.md](../decisions/0005-per-person-stress.md)

**実装との差分**：親側（月給・地位・ワークライフバランス・ストレス）は `ParentStatus` に実装済み。**子ども側（ストレス・成績・趣味・体調）はまだ存在しない。** → [../code/architecture.md](../code/architecture.md) 3章・7章

### ストレス値の段階（全員共通）
- 0–30：良好　／　31–70：普通　／　71–90：危険（badリスク）　／　91–100：限界（子はこの状態が続くと家出カウント進行）

## 3. 親：ワークライフバランスの数値効果（たたき台）

スライダー位置を 0（完全ライフ）〜100（完全ワーク）とする。効果は「1ヶ月ごとの精算」で反映。
※ 実装側の `WorkLifeBalance` は 0–1 の float。変換に注意。この表の月給補正は `ParentStatus.BalanceMultiplier()` として実装済み（ただし補正がかかるのは日給で、月給そのものは役職だけで決まる）。

> **2026-10-09 決定**：スライダーを一番ライフ寄り（0）にしたら「休み」扱いで、会社の給料は入らない（×0）。1〜20 は ×0.8 のまま。→ [company-support.md](company-support.md) 6章

| 位置 | 月給補正 | その親のストレス変化 | 昇進スピード | 子との時間（成績/趣味／子ストレス） |
|---|---|---|---|---|
| 0–20 ライフ強 | ×0.8 | −5 | なし | 多（成績/趣味+・子ストレス−） |
| 21–40 | ×0.9 | −2 | 遅い | やや多 |
| 41–60 中庸 | ×1.0 | +2 | 標準 | 普通 |
| 61–80 | ×1.2 | +6 | 速い | 少（成績/趣味−・子ストレス+） |
| 81–100 ワーク強 | ×1.5 | +10 | 最速 | 極少（成績/趣味−−・子ストレス++） |

→ お金と地位を追うほど子との時間が減り、成績・趣味が伸びず、**子のストレスが上がって家出リスク**に近づく。
→ 「お金 ↔ 子の幸福」という、この企画の核心のジレンマ。

### 月給の基準
- スケッチの「33万〜」を課長クラスの基準として、地位で階段状に変動させる想定。

## 3.5 子：勉強⇔遊びバランスの数値効果（たたき台）

親のスライダーと同じUIで、子ども版。位置を 0（完全に勉強優先）〜100（完全に遊び優先）とする。

| 位置 | 成績の伸び | 趣味の伸び | 子ストレス変化 |
|---|---|---|---|
| 0–20 勉強強 | ＋＋ | ほぼ0 | +6（させすぎ） |
| 21–40 | ＋ | わずか | +2 |
| 41–60 中庸 | やや＋ | やや＋ | ±0 |
| 61–80 | わずか | ＋ | −2 |
| 81–100 遊び強 | ほぼ0 | ＋＋ | −5 |

→ 勉強に振れば **大学・研究者などの職業**、遊びに振れば **推薦・スポーツ選手・ミュージシャンなどの職業** に近づく（[ending.md](ending.md) 5章）。
→ ただし勉強に振りすぎると子ストレスが上がり、放置すると家出リスク。**「成績 ↔ 趣味・心の余裕」** が子ども版のジレンマ。
→ 親（ライフ⇔ワーク）と子（勉強⇔遊び）の2本のスライダーが噛み合う：親がライフ寄りで一緒に過ごすと、子の勉強も趣味も伸ばしやすい。

## 4. 食事システムの数値効果（たたき台）

| グレード | 費用/月 | ストレス（**全員に同じ量**） | イベント発生率 |
|---|---|---|---|
| 最安値 | 30,000 | +5 | Badイベント +5% |
| 普通 | 90,000 | −2 | ±0 |
| 高級 | 150,000 | −5 | Goodイベント +5% |

→ 家族は同じものを食べるので、母親・父親・子どもに同じ量が入る。→ [../decisions/0005-per-person-stress.md](../decisions/0005-per-person-stress.md)
→ 「節約してお金を残すか、家族のストレスのためにお金を使うか」のトレードオフ。
→ 詳細と、今後足す効果の候補は [food-system.md](food-system.md)。

## 5. 子の成長ステータスの動き（考え方）

- **成績**：勉強⇔遊びスライダーの勉強寄り、オンライン学習アプリ、親のライフ寄り（勉強を見る時間）、良い環境で上昇。放置・体調不良で低下。→ 受験の合否と、成績重視の職業に効く。
- **趣味**：勉強⇔遊びスライダーの遊び寄りやイベントで「発見」→ 継続で熟練度アップ。例：スポーツイベントで運動好きが判明。→ 推薦と、趣味に合った職業に効く。趣味の充実は子ストレスも下げる。
- **体調**：デメリットイベント（風邪等）で低下。食事・医療・予防接種で回復・予防。
- **ストレス（子）**：セクション1参照。家出＝ゲームオーバーの引き金なので、UIで常に見える位置に。
- **good/bad状態**：一時フラグ。例）風邪＝体調−・学校休み／絶好調＝成績・趣味に一時ボーナス。
