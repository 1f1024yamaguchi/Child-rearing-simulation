# ストーリーウィンドウ（設計・2026-11-11）

> イベントの選択でその後の展開が変わる「ストーリー」を、全体で見て管理するためのエディタ拡張。
> **イベントの編集ウィンドウ（event-editor.md）とは別のツール**にする（2026-11-11 決定）。
> イベントの編集ウィンドウ＝「1つのイベントを作る」道具／ストーリーウィンドウ＝「イベント同士のつながり全体を見る・フラグを管理する」道具。
> ランタイムの仕組み（StoryState・StoryFlag・条件の部品・効果の種類・続きのイベント）は [event-editor.md](event-editor.md) 4章。このツールはそれを見る・編集するだけで、ランタイムには何も足さない。
> 作るのは event-editor.md の段階⑥（①〜⑤が終わってから。フラグや続きの仕組みが無いと見せる中身が無いため）。リポジトリでは `docs/design/story-tool.md` に置く。

---

## 1. 何に困るのを防ぐか

| 困りごと | このツールでの解決 |
|---|---|
| フラグがどこで立って、どこで見られているか分からない | フラグごとに「立てる／消す／見る」場所を一覧（逆引き） |
| 立てるだけで誰も見ていない・見ているのに誰も立てないフラグに気づけない | ⚠ を出す |
| 「野球」の話がどのイベントにまたがっているか追えない | 流れ図で、1つのフラグ・イベントから辿れる分だけ表示 |
| 分岐するストーリーの文章（チュートリアル）がどこにあるか分からない | ストーリー用のチュートリアルとページの出す条件を一覧 |
| 年齢ジャンプのあと、今どの分岐にいるか分からない | 再生中にフラグ・選んだ履歴・予約中の続きを表示・変更 |

## 2. ウィンドウの全体

メニュー：**子育て → ストーリー → ストーリーウィンドウ**

```
[フラグ] [流れ図] [ストーリーの文章] [再生中の状態]
```

### 2.1 フラグ

```
[＋新しいフラグ]  検索 [        ]
  野球をやっている   趣味の呼び名：野球（スポーツ）   立てる2・消す1・見る3   ⚠0
  ピアノを習っている 趣味の呼び名：ピアノ（音楽）     立てる1・消す0・見る0   ⚠1
── 選んだフラグ ────────────
  ID [baseball]（作ったあとは変えない。セーブのキー）  表示名 [野球をやっている]  説明 [...]
  趣味の呼び名  ☑ [野球]  分類 [スポーツ▼]
  立てる  「野球教室の体験会」→ 通わせる
  消す    「野球をやめたい」→ やめさせる
  見る    イベント「少年野球の大会」（条件）／チュートリアル「野球を始めた」（出すタイミング）／職業「プロ野球選手」（条件）
  ⚠ ここで使われていません …
```
- 新しく作ると `Assets/Yamaguchi/Data/Story/Flags/Flag_<ID>.asset` に保存。ID はファイル名から自動（英数字と _ のみ・重複は ✕）。
- 名前（表示名）は変えてよい。ID は変えない（セーブが外れるため）。
- 削除は「どこからも使われていないとき」だけ押せる。
- 行を押すと、イベントの編集ウィンドウ・チュートリアルの編集ウィンドウ・支援制度の編集ウィンドウ（職業は Inspector）へ移る。

チェック：

| 印 | 内容 |
|---|---|
| ✕ | ID が空・重複・英数字と _ 以外 |
| ⚠ | 立てる場所が無いのに、見ている場所がある（条件が永遠に満たされない／満たされ続ける） |
| ⚠ | 立てる場所はあるのに、見ている場所が無い（意味のないフラグ） |
| ⚠ | 趣味の呼び名があるのに分類が「なし」 |

### 2.2 流れ図

```
絞り込み：[フラグ ▼ 野球をやっている] [イベント ▼] [年齢 0〜22]   [全部]
 6歳            7歳                 10歳             18歳
 ┌野球教室┐ ─通わせる→ ┌初めての試合┐
 │の体験会│              └──────┘
 └────┘ ─通わせる→ (野球をやっている) ┄┄→ ┌少年野球の大会┐ ┄┄→ [職業 プロ野球選手]
           └─やめておく┄┄→ ┌別の習い事のさそい┐
```

| 線 | 意味 |
|---|---|
| 実線の矢印 | 選択肢が「続き」を予約する（○日後を線の上に） |
| 点線の矢印 | 前の選択を条件にしている（選んだ／選ばなかった） |
| （丸い箱）フラグ | 選択肢が立てる → フラグ → 条件で見る |
| 四角い箱 | イベント（メリット＝緑・デメリット＝赤の帯、決まった日＝◆） |
| [ ] の箱 | 職業・チュートリアル（イベントの外でフラグを見ているもの） |

- 横軸は年齢（イベントの条件・決まった日から出る一番早い年齢に置く。年齢の決まらない「続き」は元のイベントの右）。縦は重ならないように並べる。
- 箱を押すとイベントの編集ウィンドウで開く。
- `GraphView` は使わず、IMGUI で箱と線を描くだけにする（Unity の版で壊れにくいため。たたき台）。ドラッグで並べ替えはしない（自動配置だけ）。
- 「全部」はイベントが多いと読めなくなるので、既定は絞り込みあり。

### 2.3 ストーリーの文章

ストーリーとして使っているチュートリアル（＝出すタイミングが「フラグが立った日」か、どこかの選択肢の効果 `ShowStory` から呼ばれているもの）の一覧。

```
  野球を始めた     出るとき：効果 ShowStory（「野球教室の体験会」→ 通わせる）  ページ3（条件付き1）
  12歳の春        出るとき：決まった年齢の日 12歳4月1日                     ページ4（条件付き2）
── 選んだもの ──
  1 「{name}が野球を始めた」          いつも出る
  2 「試合で活躍！」                  条件：フラグ 野球をやっている
  3 「ピアノの発表会も近い」          条件：フラグ ピアノを習っている
  [チュートリアルの編集ウィンドウで開く]
```
- ここでは見るだけ。編集はチュートリアルの編集ウィンドウで行う。
- 「このフラグの組み合わせだとどのページが出るか」を、フラグにチェックを入れて試せる（再生しなくてよい）。

### 2.4 再生中の状態

- 立っているフラグ（チェックで付け外し）。
- 選んだ選択肢の履歴（日付・イベント・選択肢）。行の［取り消す］で記録だけ消せる（効果は戻らない旨を表示）。
- 予約中の続き（イベント・出る日）。［今すぐ出す］［予約を消す］。
- これから出る予定のストーリー（フラグが立った日＋ずらす日数）。
- 注意書き：「ここで変えたフラグはセーブに残ります。効果（お金など）は戻りません」。
- イベントの編集ウィンドウの「再生中だけ」欄と部品を共有する。

## 3. スクリプトの分け方（すべて Editor・新規）

`Assets/Yamaguchi/Scripts/Editor/Story/`

| ファイル | 役目 |
|---|---|
| `StoryWindow.cs` | メニュー・タブの切り替えだけ |
| `StoryFlagTab.cs` | フラグの一覧・作成・名前変更・削除・逆引き・チェック |
| `StoryFlagFactory.cs` | フラグのアセットを作る・ID の自動生成と重複確認 |
| `StoryIndex.cs` | 索引（フラグ・イベント・チュートリアル・職業・支援制度の「立てる／消す／見る／続き」）。イベントの編集ウィンドウの `EventRegistry` が持つ索引を使い、足りない分（チュートリアル・職業）だけ足す |
| `StoryGraphTab.cs` | 流れ図の描画・絞り込み・クリック |
| `StoryGraphLayout.cs` | 箱の並べ方（年齢で横・重なりで縦） |
| `StoryTextTab.cs` | ストーリーの文章の一覧・フラグの組み合わせでページを試す |
| `StoryPlayModeTab.cs` | 再生中の状態（`StoryState` の窓口を通して変更する） |

- 索引は、アセットが変わったとき（`OnProjectChange`）に作り直す。毎フレーム作らない。
- 変更は必ず `StoryState` の窓口（`SetFlag` など）を通す。中のリストを直接触らない（通知が出ないため）。

---

## 4. 決めないといけないこと

- 流れ図の「全部」表示の上限（イベント何個まで出すか）。
- 履歴の［取り消す］を入れるか（デバッグには便利だが、効果が戻らないので混乱しやすい）。
- 職業（CareerDefinition）がまだ無いので、職業の箱は CareerDefinition ができてから出す。
