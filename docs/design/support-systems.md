# 子育て支援制度とボタン設計

> 画面下部の「政府」ボタンの仲間として、どんなカテゴリボタンを用意すべきかの整理。
> 実在の制度（2025〜2026時点）をベースに、ゲーム用に分類。**数値はゲーム側で調整前提。**
> **支援は「ノーリスクの得」ではなく、現実どおりデメリット／自己負担をつける**方針（セクション2.5）。→ 経緯は [../decisions/0002-support-systems-have-drawbacks.md](../decisions/0002-support-systems-have-drawbacks.md)
> 一覧画面の実装状況は [../code/ui-scroll-patterns.md](../code/ui-scroll-patterns.md)。

## 1. ボタンは「制度の出どころ」で分けるのがおすすめ

現在：下部に「政府」ボタン＋空き枠が2つ。制度は**誰が出しているか（出どころ）**で分けると、プレイヤーが直感的に探せる。推奨は4カテゴリ：

| ボタン | 出どころ | アイコン案 |
|---|---|---|
| 政府（国） | 国の制度 | 国会議事堂（現状のアイコンでOK） |
| 自治体 | 市区町村の制度 | 役所・家のマーク |
| 会社・仕事 | 勤務先／雇用保険 | ビル・バッグ |
| アプリ | 民間の便利サービス | スマホ |

→ 空き枠2つには「自治体」「アプリ」を入れると、当初コンセプト（政府・自治体・アプリ）と一致。
→ このゲームは**ワークライフバランス**が肝なので、育休・時短が入る「会社・仕事」を4つ目に足すと、親のステータスと強く噛み合う（枠を3→4に増やす価値あり）。

## 2. カテゴリ別の制度（メリット＋現実のデメリット）

### 政府（国）
| 制度 | メリット | 現実のデメリット・注意 |
|---|---|---|
| 児童手当 | 高校生年代まで毎月／第3子以降 月3万 | 申請しないと0円・現況届などの手続き継続が必要 |
| 出産育児一時金 | 出産で原則50万円 | 出産費用がこれを超えると差額は自己負担 |
| 出産・子育て応援給付金 | 計10万円相当 | 面談・申請が前提 |
| 幼児教育・保育の無償化 | 3〜5歳の保育料が無料 | 給食費・延長保育・行事費は対象外で自己負担。そもそも入園できないと無意味（待機児童） |
| 高等学校等就学支援金 | 高校の授業料を支援 | 所得制限あり（高所得は減・対象外）／私立は差額自己負担／申請必要 |

### 自治体（市区町村）
| 制度 | メリット | 現実のデメリット・注意 |
|---|---|---|
| 子ども医療費助成 | 通院・入院費が軽減 | 自治体で差、引っ越すと変わる／窓口で一旦立替の場合も |
| 一時預かり／病児保育 | 急な時に子を預けられる | 利用料がかかる／予約が取りにくい／子が泣く・感染症をもらう（子ストレス・体調−） |
| ファミリーサポート | 送迎・預かりを助け合う | 事前登録・打合せの手間／相手との相性・事故リスク |
| 子育て支援センター | 相談・交流で不安が減る | 開所時間・場所が限られる |
| 学童保育 | 放課後も子を見てもらえる | 定員・待機／時間制限／費用 |
| 予防接種の公費助成 | 体調イベントの発生率↓ | 副反応で一時的に発熱（体調−）／スケジュール管理 |
| 給食費・教材費の補助 | 支出減 | 所得などの条件つき |

### 会社・仕事（勤務先／雇用保険）
| 制度 | メリット | 現実のデメリット・注意 |
|---|---|---|
| 育児休業給付金 | 育休中も賃金の67%（181日以降50%） | 手取りは減る／キャリア停滞・復帰後の居場所（マミートラック） |
| 出生後休業支援給付金 | 序盤 最大28日ぶん手取り10割相当 | 夫婦で育休が条件／期間限定 |
| 育児時短就業給付金 | 時短の減収を一部補填 | あくまで一部。時短＝昇進が遅れやすい |
| 時短勤務・残業免除 | 両立しやすい | 給料が減る／昇進が遅れる／周囲へのしわ寄せ |

### アプリ・民間サービス
| サービス | メリット | 現実のデメリット・注意 |
|---|---|---|
| 学習アプリ | 子の成績＋ | 月額課金／子が飽きる／スクリーンタイム増 |
| 家計簿アプリ | 無駄遣いイベント減 | 続けないと効果なし（手間） |

## 2.5 デメリットの「型」（これをゲームのコストに割り当てる）

支援ごとにバラバラに考えず、以下の型に落とすと実装・バランス調整が楽：

1. **申請の手間 / 時間コスト** … 知らない・忘れると受けられない。申請に親の行動や時間を消費。
2. **お金がかかる** … "支援"でも自己負担が残る（給食費、利用料、月額課金）。
3. **所得・条件で対象外** … 高所得だと減る／私立は差額／家庭状況の条件。
4. **収入・キャリアが下がる** … 育休・時短は手取り減・昇進遅れ（親の月給／地位にマイナス）。
5. **待機・定員・運** … 保育園に入れない、予約が取れない（成功しないことがある）。
6. **副作用** … 子ストレス／体調／依存（一時預かりで泣く・感染症、アプリでスクリーンタイム）。
7. **手続きの継続** … 現況届などを出し忘れると停止・失効。

→ 「良い制度を、コストを払ってどう使うか」という判断ゲームになる。テーマ（制度を知る）とも一致。
→ **実装時はこの7つを enum などで型として持たせる**と、制度データを追加するのが楽になる。

## 3. 「制度一覧」画面の考え方

- カテゴリボタンを押すと、その出どころの制度が**一覧**で出る。
- 各制度カードに **メリット（緑）とデメリット（赤）の両方**を並べて表示 → ノーリスクに見せない。
- さらに**状態**を表示して「知っていれば得する」を演出：
  - 受給中（緑）：今もらえている
  - 申請できる（オレンジ＋申請ボタン）：条件を満たしたが未申請 → 申請し忘れると損
  - 条件未達（グレー）：まだ対象外（例：子が3歳で無償化 など）
- 制度カードの中身：アイコン／名前／ひとこと説明／メリットチップ／デメリットチップ／状態バッジ（＋申請ボタン）。
- 上部にタブ（政府・自治体・会社・アプリ）を置き、切り替えられると1画面で完結。
