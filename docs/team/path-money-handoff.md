# 進路とお金（有坂さんへの引き継ぎ）

> 作成：2026-11-18（山口／Claude）
> 目的：進路（高校受験・大学・専門・浪人・留年）で **どんなお金が動くか** をそろえる。
> 分担：**お金の増減（家計簿・支出・奨学金）は有坂さん**。**進路側のデータ・合図・条件の部品は山口側（Claude）が作る**。
> 状態：金額はすべて **仮**。支出の仕組みは `docs/design/expenses.md`（`ExpenseItem`・`CostTier`・`RequirementSO`/`GameContext`）に合わせた。`antigravity-ending.md` の依頼8（学費・授業料の減免）がこのメモの対象。

---

## 1. 進路で、いつ・どんなお金が動くか

| いつ | 出来事 | 動くお金 | 備考 |
|---|---|---|---|
| 中3の2月 | 公立高校の受験 | 受験料 | 落ちると私立高校（次の行） |
| 高1の4月〜 | 私立高校（公立に落ちた場合） | 入学金・授業料・制服代 | 公立より高い。高校就学支援金（授業料 月9,900まで）との差額が自己負担 |
| 高1〜高3 | 高校の学校費 | 年ごとの学習費 | **既にある**：`hs_tuition`（授業料 9,900/月・就学支援金で肩代わり）と `hs_other`（19,400/月）。expenses.md 6.2 |
| 高3の11月 | 推薦の受験 | 受験料 | 受かれば入学へ |
| 高3の2月 | 一般入試（大学・専門） | 受験料 | 落ちたら浪人・就職・専門を選び直す |
| 合格の翌4月 | 入学（専門2年／大学4年） | 入学金（1回）・授業料（毎年）・教材など | 巣立ちの日 = 入学年度 + 在学年数 + 留年 の4月1日 |
| 浪人中 | 浪人（何年でも可） | 予備校代（毎年）・受験料（毎年） | 学校費は無し |
| 在学中の3月 | 学年の平均が足りないと留年 | もう1年ぶんの授業料 | 留年しても巣立ちが1年のびるだけ |
| 就職を選ぶ | 就職 | なし | 巣立ちで終わる |

## 2. 必要なお金の設定（山口側で `PathDefinition` に足す予定のデータ）

進路1つにつき、次の項目を持たせる。**有坂さんはこの値を読んで、お金を動かすだけ**にする。

| 項目 | 内容 | 使う場面 |
|---|---|---|
| `examFee` | 受験料（1回） | 受験した瞬間 |
| `entranceFee` | 入学金（1回） | 入学した瞬間（4月1日） |
| `tuitionPerYear` | 授業料（年） | 在学中の毎年（月割か年払いかは §4 で決める） |
| `otherPerYear` | 教材・制服・予備校など（年） | 在学中・浪人中の毎年 |

仮の金額（たたき台。**出典を確かめていない**ので、決める前に文科省・日本学生支援機構の資料で確認する）：

| 進路 | 受験料 | 入学金 | 授業料／年 | その他／年 |
|---|---|---|---|---|
| 公立高校 | 約0.3万 | ― | 就学支援金でほぼ無し | 学校費（既存） |
| 私立高校 | 約2万 | 約20万 | 約40万（支援金の差額後） | 制服・教材 約10万 |
| 専門学校（2年） | 約2万 | 約20万 | 約100万 | 約20万 |
| 大学（4年）・推薦 | 約3.5万 | 約28万（国公立）〜25万前後（私立） | 約54万（国公立）〜約100万（私立） | 約10万 |
| 浪人 | 約3.5万（毎年） | ― | ― | 予備校 約80万 |

「国公立か私立か」は今の進路アセットに無い。**分けるか、1つの平均にするか**は決めてほしい（§4）。

## 3. 進路側から渡す情報（合図と状態）

### 3.1 既にある合図（`PathSystem` のイベント）
- `OnPathChanged(PathDefinition)`：進路が決まった・変わった
- `OnExamResult(ExamRecord)`：受験の結果が出た（種類・進路・合否）
- `OnRetryChoiceNeeded` / `OnRepeatYear`：浪人などの選び直しが必要／留年した

### 3.2 追加する予定の合図（山口側。**まだ作っていない**）
- `OnEnrolled(PathDefinition)`：入学した（入学金を引く合図）
- `OnHighSchoolResult(bool isPrivate)`：高校受験の結果（私立の入学金を引く合図）
- 受験料の合図は `OnExamResult` で足りる想定

### 3.3 読める状態
`PathSystem.I` から：`CurrentPath`（在学中・就職）／`TargetPath`（決めた進路）／`State.enrolled`／`State.yearInSchool`／`State.roninCount`／`State.repeatCount`／`State.isPrivateHighSchool`

### 3.4 条件の部品（山口側で作る予定）
`RequirementSO` を継ぐ `PathStateCondition`（在学中の進路が○○／浪人中／私立高校／在学○年目）。
有坂さんが `ExpenseItem` の `CostTier`（年齢の段＋条件）や支援制度の条件に、**コードを書かずに** 使える。
例：「大学授業料」= 条件「在学中の進路が大学」の段を1つ置く。受験料・入学金のような1回払いは、§3.2 の合図で払う。

## 4. 決めてほしいこと

1. **授業料の払い方**：（a）毎月 ÷12 を引く ／（b）4月に1年ぶんまとめて引く。
   - おすすめ（a）：このゲームは月ごとの精算で、一度に大きく引くと赤字になりやすい。
   - 入学金・受験料は、その場で一括。
2. **国公立と私立を分けるか**：分けるなら進路アセットを増やす（大学（国公立）・大学（私立））。分けないなら平均の金額を1つ。
   - おすすめ：最初は分けない。奨学金・修学支援が入ってから必要なら分ける。
3. **お金が足りないとき**：（a）進路を決める画面で「選べない」にする ／（b）選べるが赤字になり、家計破綻に近づく。
   - `ending.md` には「お金が足りない進路は修学支援・奨学金で開ける」とある。設計どおりにするなら（a）＋奨学金。
4. **奨学金・修学支援をどこまで作るか**：
   - 修学支援：所得で授業料減免（高校就学支援金と同じ型で足せる）
   - 貸与型奨学金：借りた額は子の将来の負担。ゲームは巣立ちで終わるので、結果画面（`totalScholarship`）に出すだけでよいか。
5. **税の扶養控除との関係**：`taxes.md` に特定扶養（19〜22歳）の控除が既にある。浪人（19歳）・大学生にも効くかの確認だけでよい。

## 5. 分担のまとめ

| 担当 | やること |
|---|---|
| 山口側（Claude） | `PathDefinition` に金額の項目を足す／合図（§3.2）を足す／`PathStateCondition` を作る／進路を決める画面に「かかるお金」を出す（金額が決まったあと） |
| 有坂さん | §2 の値の設計（金額・出典）／合図を受けてお金を動かす（家計簿・支出）／奨学金・修学支援の仕組み |

進路の判断画面（専用パネル）は作成済み。カードに「かかるお金」を1行足せる作りにしてある（金額が決まってから足す）。

私立高校は今は「公立に落ちた」フラグ（`isPrivateHighSchool`）だけで、進路アセットが無い。金額を持たせるには、進路の種類に「私立高校」を足してアセットを作る必要がある（山口側）。
