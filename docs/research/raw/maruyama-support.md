# 子育てシミュレーションゲーム：イベント・サポート制度の企画共有資料

## 1. ゲームの基本方針

子どもの誕生から大学・専門学校卒業までをシミュレーションし、親の選択によって子どもの成長や家庭の状況が変化するゲームを制作する。

### ゲーム内で管理する主なパラメータ
- **家計のお金**：教育費、習い事、病気・ケガ、生活費などで増減する。
- **親のストレス**：子育てや仕事、病気への対応などで増減する。
- **子どものストレス**：学業、人間関係、家庭環境などで増減する。
- **子どもの能力・経験値**：勉強、趣味、運動などのイベントで増減する。

※具体的なパラメータや数値は、既存のゲームシステムに合わせて調整する。

## 2. ライフステージ別イベント一覧

### ① 誕生～就学前（0～5歳）

| 時期 | イベント | 内容・ゲームへの反映 |
|---|---|---|
| 誕生時 | 赤ちゃん誕生・命名 | 誕生シーンと名前を決めるイベント。余裕があれば実装 |
| 0歳～ | 初めての言葉 | 「赤ちゃんがママと言いました」など。親のストレス減少 |
| 0歳～ | 初めて立つ | 子どもの成長を実感し、親のストレス減少 |
| 0歳～ | 病気・風邪 | 病気への対応を選択。一時預かり保育などを利用する |
| 0歳～ | 保育園等への入園 | 保育施設を選択し、保育料や利用できる支援制度が変化 |
| 3歳～ | 幼稚園への入園 | 幼稚園を選択肢に追加。保育料や預かり保育の支援を反映 |
| 4歳～ | 習い事 | 習わせるかどうかを選択。費用や趣味経験値などが変化 |
| 就学前 | 発表会・お遊戯会 | 子どもの成長を描くイベント。親のストレス減少 |
| 卒園時 | 卒園イベント | 保育園・幼稚園の卒園を演出 |

**保育施設の選択肢（案）**
- 保育園
- 認定こども園
- 認証保育所・認可外保育施設
- 幼稚園（3歳以降）
- 自宅保育

※施設の細かな違いをすべて実装するのではなく、まずは費用・利用条件・支援制度の違いを中心に表現する。

**病気イベントの発生頻度（案）**
- 0歳から小学校入学前までを主な対象とする。
- 毎月必ず発生させるのではなく、ランダム発生を基本とする。
- 入園後や冬季、季節の変わり目などに発生しやすくする案も検討する。
- 一時預かり保育などを利用した場合の費用と、親のストレス軽減を反映する。

| 時期 | イベント | 内容・ゲームへの反映 |
|---|---|---|
| 6歳4月 | 小学校入学式 | 公立小学校へ入学。義務教育のため進学は必須 |
| 毎年 | 誕生日 | 子ども・親のストレス減少 |
| 毎年 | 健康診断 | 健康状態の確認 |
| 毎年 | 定期テスト・成績 | 結果に応じて勉強経験値やストレスが変化 |
| 毎年 | 学校行事 | 運動会、発表会など |
| 習い事中 | 大会・発表会 | 成績や経験に応じて結果が変化 |
| 随時 | ケガ・病気 | 治療費や親の対応が発生 |
| 余裕があれば | 友達ができる・ケンカ | 人間関係によってストレスが変化 |
| 余裕があれば | 修学旅行 | 家計への影響や子どもの経験値を反映 |
| 11～12歳頃 | 小学校卒業 | 卒業イベント |

**進学方針（案）**
- 小学校は公立のみとし、受験・私立小学校の要素は実装しない。
- 就学援助や給食費の負担軽減など、経済的支援を反映する。

### ③ 中学校（12～14歳）

| 時期 | イベント | 内容・ゲームへの反映 |
|---|---|---|
| 12歳4月 | 中学校入学 | 公立・私立を選択 |
| 入学後 | 部活動への入部 | 部活動を選択。趣味経験値やストレスに影響 |
| 随時 | 部活動でのケガ | 治療費や活動への影響 |
| 随時 | 大会・コンテスト | 結果に応じて経験値などが変化 |
| 毎年 | 定期テスト・健康診断 | 成績や健康状態を確認 |
| 随時 | 反抗期 | 親子関係やストレスに影響 |
| 随時 | 友達とのケンカ・仲直り | 人間関係イベント |
| 余裕があれば | 修学旅行 | 費用や経験値に影響 |
| 15歳頃 | 卒業イベント | 公立中学校の場合、高校受験へ進む |

**進学方針（案）**
- 公立中学校・私立中学校を選択できる。
- 私立中学校を選択した場合は、中高一貫校への進学として扱い、高校入学イベントを省略する。
- 公立中学校の場合は、高校受験イベントを経て高校へ進学する。

### ④ 高校（15～17歳）

| 時期 | イベント | 内容・ゲームへの反映 |
|---|---|---|
| 15歳4月 | 高校入学 | 公立・私立を選択 |
| 毎年 | 定期テスト・健康診断 | 成績や健康状態を確認 |
| 随時 | 部活動・大会・コンテスト | 経験値やストレスに影響 |
| 随時 | ケガ・病気 | 治療費などが発生 |
| 余裕があれば | 文化祭・修学旅行 | 学校行事を体験 |
| 余裕があれば | 進路相談 | 大学・専門学校への進学を考える |
| 18歳頃 | 高校卒業 | 大学・専門学校受験イベントへ |

**進学方針（案）**
- 公立高校・私立高校を選択できる。
- 商業高校・工業高校・高等専門学校などの細かな進路は、余裕があれば追加する。
- 私立中高一貫校を選んだ場合は、高校入学イベントを発生させない。

### ⑤ 大学・専門学校（18歳～）

| 時期 | イベント | 内容・ゲームへの反映 |
|---|---|---|
| 18歳頃 | 進路選択・受験 | 就職か進学かを選択 |
| 18歳4月 | 大学・専門学校入学 | 学校種別と国公立・私立などを選択 |
| 入学後 | 健康診断 | 健康状態を確認 |
| 20歳頃 | 成人式 | 成人を祝うイベント |
| 卒業時 | 大学・専門学校卒業 | ゲーム終了に向けたイベント |
| 最終 | エンディング | 子どもの成長と家庭の結果を表示 |

**進路の選択肢（案）**
- 就職：ゲーム終了
- 国立大学
- 公立大学
- 私立大学
- 国立・公立・私立の専門学校

※短期大学は今回は対象外とする。文系・理系の選択も、実装に余裕があれば追加する。

## 4. 習い事イベントの仕様案

**発生時期：4歳頃から**

子どもが習い事を希望したときに、親が選択する。

| 選択肢 | 効果 |
|---|---|
| ① 習わせる | 家計のお金が減少、趣味経験値が増加。送迎などにより親の負担が増える場合もある |
| ② 習わせない | 家計の変化なし。子どもの希望がかなわない場合、子どものストレスが増加する可能性 |

追加で検討すること：
- 同時に習える習い事の最大数
- スポーツ・音楽・学習などの種類
- 習い事に応じた大会・発表会・ケガイベント
- 習い事を辞めるイベント

## 5. サポート制度の設計

### 基本方針

国の制度を基本とし、東京都・北区独自の支援を追加する。進学先や保育施設、世帯状況によって利用できる制度を変化させる。

支援制度を単なる説明で終わらせず、**申請するかどうかをプレイヤーが選び、家計への影響を体験できる仕組み**にする。

### ① 保育園・幼稚園

| 支援制度 | 主な対象・条件 | ゲームへの反映 |
|---|---|---|
| 幼児教育・保育の無償化 | 年齢、施設、保育の必要性などによって条件が異なる | 保育料の負担を軽減 |
| 0～2歳児の保育料支援 | 国の制度に加え、北区独自の支援もある | 所得や施設に応じて負担額を変更 |
| 預かり保育等の補助 | 保育の必要性の認定などが条件 | 対象者は利用料の一部を軽減 |
| 幼稚園関連の補助 | 入園時、保育料、預かり保育、給食費など | 入園・在園にかかる費用を軽減 |

### ② 小学校

| 支援制度 | 主な対象・条件 | ゲームへの反映 |
|---|---|---|
| 就学援助 | 所得などの要件を満たす世帯 | 学用品などの購入費を補助 |
| 特別支援教育就学奨励費 | 対象となる特別支援教育を受ける児童など | 学用品費・通学費などを補助 |
| 給食費の無償化 | 北区立学校など対象となる学校 | 給食費の負担を軽減 |
| 児童手当 | 子どもの年齢・出生順位などに応じた国の制度 | 家計に定期的な収入を反映 |

### ③ 中学校

| 支援制度 | 主な対象・条件 | ゲームへの反映 |
|---|---|---|
| 就学援助 | 所得などの要件を満たす世帯 | 制服・学用品などの負担を軽減 |
| 給食費の無償化 | 北区立学校など対象となる学校 | 給食費の負担を軽減 |
| 私立中学校等授業料軽減助成 | 対象となる私立中学校等の在籍者など | 私立中学校の授業料負担を軽減 |
| 特別支援教育就学奨励費 | 対象となる特別支援教育を受ける生徒など | 学用品費・通学費などを補助 |
| 受験生チャレンジ支援貸付 | 所得などの要件を満たす受験生世帯 | 塾代・受験料などの負担を軽減する仕組みを再現 |

### ④ 高校

| 支援制度 | 主な対象・条件 | ゲームへの反映 |
|---|---|---|
| 高等学校等就学支援金 | 対象となる高校等の在籍者 | 授業料の負担を軽減 |
| 東京都の授業料軽減助成 | 対象となる都内私立高校等の在籍者など | 私立高校の授業料負担を軽減 |
| 高校生等奨学給付金 | 所得などの要件を満たす世帯 | 教科書・教材など授業料以外の費用を補助 |
| 受験生チャレンジ支援貸付 | 所得などの要件を満たす受験生世帯 | 塾代・受験料などの負担を軽減する仕組みを再現 |

### ⑤ 大学・専門学校

| 支援制度 | 主な対象・条件 | ゲームへの反映 |
|---|---|---|
| 高等教育の修学支援新制度 | 所得・資産、学校、学業などの要件。多子世帯には別の要件・支援範囲がある | 授業料・入学金の減免、給付型奨学金 |
| 教育支援資金 | 低所得世帯などの要件を満たす場合 | 入学金・在学中の教育費を貸付で支援 |
| 受験生チャレンジ支援貸付 | 対象となる受験生世帯 | 受験費用の負担を軽減 |
| 学校独自の奨学金 | 学校ごとの条件による | 条件を満たした場合に費用を軽減 |
| 北区奨学金返済支援給付事業 | 卒業後の居住・奨学金返済などの要件 | 卒業後の支援としてエンディングなどで紹介 |

※貸付制度は給付制度と異なり、原則として返済が必要。返済免除の要件がある制度は、その条件も区別する。

### サポート制度のゲーム内フロー

1. 入園・入学イベントで、施設や学校を選択する。
2. 家庭の所得などの条件を確認する。
3. 利用できる支援制度と、利用できない制度を表示する。
4. 申請するかどうかを選択する。
5. 支援が認められた場合、家計のお金や教育費に反映する。

利用できない制度も表示し、対象外となる理由を短く説明することで、制度について学べるようにする。

例：
- **申請可能**：就学援助（所得などの条件を満たす場合）
- **申請対象外**：所得基準を超えているため対象外
- **注意事項**：貸付制度は返済が必要

※実際の制度は年度・施設・所得・家族構成などで条件が異なるため、ゲームに反映する金額や要件は実装時に公式情報を確認する。

## 6. 学校・施設選択時の注釈

進学先や保育施設の選択画面に、費用・メリット・デメリットを簡潔に表示する。

| 選択肢 | メリットの例 | デメリットの例 |
|---|---|---|
| 保育園 | 保護者の就労と両立しやすい | 保育の必要性などの利用条件がある |
| 幼稚園 | 教育活動や園ごとの特色がある | 預かり時間や追加費用に差がある |
| 公立中学校 | 私立に比べ授業料以外の教育費を抑えやすい | 学校・コースを選ぶ自由度が限られる場合がある |
| 私立中学校 | 学校独自の教育や中高一貫教育を受けられる | 授業料や施設費などの負担が大きくなりやすい |
| 公立高校 | 私立より授業料以外も含めた費用を抑えやすい傾向 | 学校ごとに選べる教育内容が異なる |
| 私立高校 | 学校独自の教育・設備・コースがある | 授業料以外の費用がかかる場合がある |
| 国公立大学 | 私立大学に比べ授業料が低い傾向 | 学部・大学によって学べる分野や入試条件が異なる |
| 私立大学 | 学部や専門分野の選択肢が多い | 学費が高くなりやすい |
| 専門学校 | 職業に直結した知識・技能を学びやすい | 学校・分野によって学費や進路が異なる |

※注釈は、プレイヤーが選択しやすいように1～2行程度にする。公立・私立の違いは一般的な傾向として扱い、すべての学校に当てはまると断定しない。

## 7. 実装優先度の提案

### 優先度A：ゲームの基本進行に必要
- 年齢・学年に応じたイベント発生
- 保育施設・中学校・高校・大学等の選択
- 入園・入学・卒業イベント
- 病気・ケガ・誕生日イベント
- 習い事イベント
- 家計・ストレス・経験値への影響
- 基本的なサポート制度の表示と申請

### 優先度B：ゲーム性を高める
- 定期テストと成績変動
- 部活動・大会・発表会
- 反抗期・友達とのケンカ
- 修学旅行・学校行事
- 支援制度の対象判定を詳しくする
- 保育施設や進学先ごとのメリット・デメリット表示

### 優先度C：余裕があれば追加
- 赤ちゃん誕生・命名の演出
- 家族旅行・お年玉・欲しいもの
- 宿題・勉強・才能の発見
- 妹・弟ができるイベント
- 保険加入
- 家出イベント・詳細なエンディング
- 文系・理系、商業・工業高校などの細かな進路分岐

## 8. 班内で相談・決定したい事項

1. **イベントの発生方式**：年齢・学年に応じた固定イベントと、確率によるランダムイベントをどう組み合わせるか。
2. **病気イベントの期間と頻度**：保育園期限定にするか、大学まで年齢に応じて発生させるか。
3. **自宅保育の扱い**：入園を拒否し続ける方式にするか、最初から選択肢に含めるか。
4. **進学先の分岐**：私立中高一貫校の扱い、高校・大学・専門学校の選択肢をどこまで実装するか。
5. **サポート制度の範囲**：北区独自の制度まで再現するか、国の制度を中心に簡略化するか。
6. **家庭状況の設定**：所得や家族構成をどう決定し、支援制度の対象判定に反映するか。
7. **ゲームオーバー条件**：家計の不足やストレスの上昇を、ゲーム終了に直結させるか。
8. **実装の優先順位**：全イベントを作るのではなく、基本進行に必要なものから完成させるか。

## 9. まとめ

今回のゲームでは、子どもの成長に合わせたイベントを発生させ、プレイヤーの選択によって家計・親子のストレス・子どもの経験値が変化する仕組みを基本とする。

サポート制度は、進学先や家庭状況に応じて利用可能な制度を表示し、申請による経済的な影響を体験できるようにする。

まずは入園から卒業までの基本進行と主要イベントを実装し、その後、学校行事・人間関係・細かな支援制度などを段階的に追加する方針とする。
