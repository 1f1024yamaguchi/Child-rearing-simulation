# raw/ — 調べた元ファイルの置き場所

スプレッドシート（CSV）やメモ帳（.txt）で調べた内容を、**形式を気にせずそのまま置く**場所。
表（`../support-systems.md` / `../expenses.md`）への書き写しは山口がまとめて行う。

- ファイル名：`<名前>-<テーマ>.<拡張子>`（例：`arisaka-expenses.csv`、`kusao-support.txt`）
- 文字コードは **UTF-8** で保存する（Windows のメモ帳は「名前を付けて保存」右下の「エンコード」で選ぶ）
- スプレッドシートは **CSV で書き出して**置く（.xlsx は置かない）。1行目を `../README.md` 2章の列名に揃えると書き写しが楽
- 最低限「金額」と「どこで見たか（URL）」があればOK
- 書き写した後も**消さない**。表の「備考」に `raw/arisaka-expenses.csv より` と元ファイルを書く
- **AI エージェントはこのフォルダの内容を仕様として使わない**
