# 賞与に対する源泉徴収税額の算出率の表(令和8年分)

- 出典: 平成24年3月31日財務省告示第115号 別表第三(令和7年4月30日財務省告示第122号改正)
- 資料: 税額表 15〜16ページ
- 用途: 賞与(ボーナス)から源泉徴収する所得税額を、「賞与の金額 × 率」で求めるための率を決める表

---

## 1. 結論(計算式)

```
源泉徴収税額 = 賞与の金額(社会保険料等控除後) × 算出率
```

- 「賞与の金額」は、賞与から社会保険料等が控除される場合は **控除後の金額** を使う。
- 算出率は **前月の給与(賞与を除く)から社会保険料等を引いた金額** と **扶養親族等の数** で決まる。
- 金額の単位は表中「千円」。「以上」「未満」で区切られている(例: 94〜260 は 94千円以上260千円未満)。

---

## 2. 用語

| 用語 | 意味 |
|---|---|
| 扶養親族等 | 源泉控除対象配偶者 + 源泉控除対象親族(詳細は税額表の使い方・19ページ) |
| 社会保険料等 | 所得税法74条2項の社会保険料 + 同法75条2項の小規模企業共済等掛金 |
| 甲欄 | 「給与所得者の扶養控除等申告書」を提出している人に使う |
| 乙欄 | 扶養控除等申告書の提出がない人(「従たる給与についての扶養控除等申告書」を出した人を含む)に使う |
| 国外居住親族 | 非居住者である親族。親族に該当する旨の証明書類が申告書に添付(または提示)されたものだけ扶養親族等の数に入れる |

---

## 3. 算出率の決め方(手順)

### 3-1. 甲欄を使う場合(扶養控除等申告書の提出あり)

1. 前月の給与等(賞与を除く)の金額から、前月の社会保険料等の金額を引く。
   - `前月の社会保険料等控除後の給与等の金額 = 前月の給与等 − 前月の社会保険料等`
2. 申告書に記載された **扶養親族等の数** を数える(下記 3-3 の加算ルールを含む)。
3. 扶養親族等の数(0〜7人以上)の列と、手順1の金額が入る行を表(第5章)で探す。
4. その行の左端「賞与の金額に乗ずべき率」が求める率。

### 3-2. 乙欄を使う場合(扶養控除等申告書の提出なし)

1. 前月の給与等の金額から前月の社会保険料等の金額を引く。
2. その金額が入る行を乙欄(第6章)で探す。
3. その行の左端の率が求める率。

### 3-3. 扶養親族等の数の加算ルール(甲欄)

申告書に次の記載があるときは、該当するごとに扶養親族等の数に **1人ずつ加算** する。

- 本人が 障害者(特別障害者を含む)・寡婦・ひとり親・勤労学生 に該当する
- 同一生計配偶者または扶養親族の中に 障害者 または 同居特別障害者 がいる(国外居住親族の場合は、親族に該当する旨の証明書類が添付または提示されたものに限る)

### 3-3-2. 子の年齢と扶養親族等の数(令和8年分)

扶養親族等の数に入るかどうかは、親族の年齢と所得の見積額で決まる。

| 親族の年齢 | 扶養親族等の数 | 備考 |
|---|---|---|
| 15歳以下(16歳未満) | **数えない** | 源泉徴収では対象外。申告書には「16歳未満の扶養親族」欄があるが、この表の人数には入れない |
| 16歳以上(控除対象扶養親族に該当) | **数える** | 令和8年分から所得要件は、所得の見積額が58万円以下から62万円以下に引き上げられる見込み(出典により扱いが異なるため、原本で確認すること) |
| 19歳以上23歳未満(特定親族) | **数える** | 控除対象扶養親族に該当しない人で、所得の見積額が100万円以下の場合。令和8年分から月々の源泉徴収にも反映される |

補足:

- 申告書の記載欄は、令和8年分から「控除対象扶養親族」ではなく **「源泉控除対象親族」** になった。
- 令和8年分の申告書の裏面にある定義欄の金額は改正前のまま印刷されており、年末調整で使う基準と一致しない場合がある。
- 実際の人数は、扶養控除等申告書の記載内容と所得の見積額で判定する。個別のケースは、国税庁の「税額表の使い方」か、勤務先の給与担当・税理士に確認すること。

### 3-4. この表を使わず「月額表」で計算する場合

次のいずれかに当てはまるときは、この表ではなく月額表を使って税額を計算する(財務省告示第115号 第3項第1号イ(2)・ロ(2)・第2号)。

- 前月中の給与等がない
- 前月の給与等が前月の社会保険料等の金額以下
- 賞与の金額(社会保険料等控除後)が、「前月の給与等 − 前月の社会保険料等」の **10倍を超える**

### 3-5. 給与の支給期が月の整数倍ごとの場合

支給期が「2か月ごと」「3か月ごと」など月の整数倍と定められているときは、賞与の直前に支払われた(支払うべき)給与等の金額と、その社会保険料等の金額を、それぞれ **倍数で割った金額** を「前月中の給与等」「前月中の社会保険料等」とみなす。

## 7. 計算例

### 例1: 甲欄・扶養0人

- 前月の給与 300,000円、前月の社会保険料等 45,000円 → 控除後 255,000円(=255千円)
- 扶養0人の列で 94千円以上260千円未満 → 率 **4.084%**
- 賞与 500,000円、賞与から引かれる社会保険料等 75,000円 → 控除後 425,000円
- 税額 = 425,000 × 4.084% = **17,357円**(1円未満は切り捨てが一般的。端数処理は税額表の使い方で確認)

### 例2: 月額表を使うケース

- 前月の給与 200,000円、社会保険料等 30,000円 → 控除後 170,000円
- その10倍 = 1,700,000円
- 賞与(社会保険料等控除後)が 1,800,000円 の場合 → 10倍を超えるため、この表は使わず月額表で計算する(第3-4章)

## 8. AI(Antigravity)向けの利用メモ

- 入力: 前月給与・前月社会保険料等・賞与額・社会保険料等控除額・扶養親族等の数(障害者等の加算込み)・甲/乙の別
- 処理順: 甲乙判定 → 月額表を使う条件(第3-4章)の確認 → 率の決定(第5・6章)→ 賞与(控除後)× 率
- 率は「以上〜未満」で判定する(境界値は上の行側に入る。例: 94千円ちょうどは 4.084%)
- 金額は千円単位の表に円単位の金額を当てはめる際、円÷1,000 で比較する
- 令和8年分の表であり、年により改正される
