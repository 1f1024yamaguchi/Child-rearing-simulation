# 2025年 産業別賞与（ボーナス）支給状況調査メモ

## 1. 全体概要（事業所規模5人以上）

- **平均支給額（支給事業所における労働者1人平均）**：**424,889円**（前年比 +2.8%）
- **平均支給月数（きまって支給する給与に対する支給割合）**：**1.08か月分**
- **賞与を支給した事業所の割合**：**76.5%**
- **賞与を支給した事業所に雇用される労働者の割合**：**86.5%**
- **全事業所における労働者1人平均賞与額（未支給事業所を含む参考値）**：**367,529円**（前年比 +1.9%）

> **※事業所規模30人以上の場合**
> - 平均支給額：**490,695円**（前年比 +2.6%）
> - 支給月数：**1.22か月分**

## 3. 主な特徴

- **高額支給傾向の産業**
  - 電気・ガス業（約94.1万円）、情報通信業（約74.7万円）、金融・保険業（約67.1万円）が上位を占めています。
- **前年比の大幅増加**
  - 複合サービス事業（+12.6%）、飲食サービス業等（+8.8%）、その他のサービス業（+7.4%）、学術研究等（+7.1%）で大きな伸びが見られます。
- **前年比で減少した産業**
  - 卸売業・小売業（-2.5%）、運輸業・郵便業（-2.0%）、電気・ガス業（-0.2%）の3産業は前年を下回っています。

## 4. ゲーム（子育てシミュレーション）への活用メモ

- **親の職業設定とボーナス収入イベント**
  - 親の職業（IT系、インフラ系、サービス系、教育系など）によって、夏・冬の賞与イベント時の支給額や月数を変動させる基準データとして活用可能。
  - 大手・事業所規模（30人以上）と中小規模（5人以上）での支給額格差（約49.1万円 vs 約42.5万円）を企業規模の差としてパラメータ化できる。
- **家計管理・教育費のスポット出費対策**
  - ボーナス月（6月・12月など）にまとまった収入が入ることで、進学費用・受験料・夏季講習費・旅行などの大きな出費に充てる設計に活かせる。
