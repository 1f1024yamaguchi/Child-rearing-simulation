# 制度カードからのカレンダー追加と期限の簡易表示・ホバー詳細ポップアップ

## 背景
サポート画面（制度一覧）で各種支援制度を見たプレイヤーが、「この制度の期限を忘れないようにしたい」と思った際、制度カード上の「カレンダーに追加」ボタンを押すことでカレンダーに締め切りが登録され、カレンダー上でその期日を視覚的に把握できるようにする必要があった。
また、カレンダーのセル（マス）は小さいため、すべての制度詳細をセル内に常時記載することはできない。簡易的に制度名やバッジを表示し、マウスカーソルを合わせたとき（ホバー操作）に大きく見やすいポップアップで詳細情報（制度名、期限、残り日数、説明文、メリットなど）を確認できる仕組みが求められた。

## 決定
1. **予定データ管理（`CalendarPlan` / `CalendarManager`）の導入**
   - 制度カードの［カレンダーに追加］が押されたとき、制度の次回期限日（`NextDeadlineAgeDays`）を取得し、`CalendarManager` に予定（`CalendarPlan`）として登録する。
   - `ISaveParticipant` を実装し、セーブデータ（`SaveSection`）として自動永続化する。
   - すでに追加されている制度はカード側でも「追加済み ✓」と表示し、トースト通知（`SupportToast`）でフィードバックを行う。

2. **カレンダー上の簡易表示**
   - カレンダー（`CalendarUI`）の各日付セル下部に、予定チップ（バッジ）を配置。
   - 予定がある日は制度名（または複数予定カウント）をアクセントカラーで簡潔に表示する。

3. **ホバー詳細ポップアップ（`CalendarDetailPopup` / `CalendarPlanHoverTrigger`）**
   - セルに `IPointerEnterHandler` / `IPointerExitHandler` を実装したトリガーを配置。
   - カーソルを合わせたときに、カレンダーウィンドウ前面に詳細カードをポップアップ表示。
   - ポップアップにはタイトル、期限日と残り日数、制度の概要（`description`）、メリット（`merits`）、支給目安などを大きく表示する。
   - カーソルが外れたら非表示にし、クリック時にも詳細を開けるようにする。

## 検討した他の案と、採らなかった理由
- **案A：カレンダーの日付マスを押したときだけ下部に詳細リストを出す方式**
  - スマホライクな方式だが、PC操作においてカーソルを合わせるだけでスピーディに確認できるホバー操作の方が直感的で使いやすいため、ホバーポップアップを採用した（クリックでも動作するように両立）。
- **案B：セル内にすべての文字を詰め込む方式**
  - セルサイズ（72×56）に収まらず、文字が重なって判読不能になるため不採用。セル内は簡易バッジとし、詳細はポップアップに分離した。
