# 設計判断の履歴（ADR）

「なぜそうなっているか」を1判断1ファイルで残す場所。後から参加した人・AI が、過去の判断を知らずにひっくり返すのを防ぐためのもの。

## 書き方

- ファイル名：`0003-短い英語の要約.md`（連番 + ハイフン区切り）
- テンプレート：[_template.md](_template.md)
- **一度書いた ADR は書き換えない。** 判断を覆すときは新しい ADR を追加し、古い方の frontmatter の `status` を `廃止` にして、新しい ADR へのリンクを追記する。
