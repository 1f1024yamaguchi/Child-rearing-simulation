# 進路の判断を専用パネルで出し、決めなかったときは子どもが自分の希望で決める

## 背景

ADR 0038 では、進路の判断をイベントのダイアログ（EventManager）で代用していた。
そのため判断の画面の上に「[メリット]／[デメリット]」の帯が出て、進路の判断に合わない見た目だった。
また、高3の7月に進路を決めなかったとき、設計に書いていない「高卒で就職」になっていた（初期のゴールと、決めていないときの職業判定の既定値がそう動くだけで、決めた挙動ではなかった）。

## 決定（2026-11-18、山口さん）

1. **進路の判断・お知らせは専用パネル `PathPanelUI`**（EventManager を使わない）。
   - 本編シーンの "School" オブジェクトに `SchoolBootstrap` が付ける。画面は自分で作り、シーンファイルには置かない（Main_test2 の衝突を避ける）。
   - 選択肢のカードを横に並べる。カードごとに模試の判定（A〜E）、★＝本人の希望、選べない理由を出す。選ぶまで閉じられない。
   - 開いている間は `GameClock.PushPause`。複数の依頼は順番に出す。お知らせは「わかった」だけの小さな板。
   - デバッグのオート処理（`DebugDialogResolver`）が、★の希望があればそれ、無ければ最初に選べるものを選ぶ。
2. **推薦は11月までに決めた場合だけ選べる**（結果が11月に出るため）。過ぎていれば「選べない」。希望にも入らない。
3. **決めなかったときの扱い**
   - 高3の7月から1月まで、決めるまで毎月出し直す（パネルは閉じられないので、ふつうは7月の1回。古いセーブなどで取りこぼしたときの保険）。
   - 2月になっても決まっていなければ、子どもが自分の希望で決める（就職を望んでいれば就職）。希望どおりなので、希望違いのストレス＋30は無い。
4. **子カード**に、学年（「中2・14歳・…」）と、進路の1行（志望／進路／在学）を足す。進路の行は高校生になってから。
   - 決める前：「志望：大学 B判定」／決めたあと：「進路：大学 B判定」（浪人中は年数つき）／在学中：「在学：大学 2年」。
5. **成長ゲージ**（Canvas/Slider）に文字を足す（`GrowthGaugeLabelUI`）。右端にゴールの名前と年月、中央に割合。ゴールが延びると割合が下がることがある。

6. **画面の文章と画像はイベントツールで作る**（2026-11-18 追記）。進路の画面10種（`PathScreens.All`：進路を決める・不合格・自動で決めた・高校の合否・推薦の3種・大学と専門の合格）を、出方「コードから」の EventData として `Assets/Yamaguchi/Resources/Events/Path/` に置く。
   - 使うのはタイトル・説明・画像（iconSprite）・お知らせのボタンの文字だけ。選択肢（進路のカード）・出方・条件・効果は使わない。アセットが無ければコードの既定の文で出す。
   - 差し込み：{name}／{path}／{ronin}／{reason}。合格は `path_pass_<進路id>` を先に探し、無ければ大学・専門の合格を使う（進路ごとに絵を変えられる）。
   - イベントツールの「新しく作る ▼」→「進路の画面をまとめて作る」、またはメニュー「子育て/進路/進路の画面をイベントとして作る」で足りない分を作る。進路の画面を開くと、何が使われるかの説明が出る。

## 検討した他の案と、採らなかった理由

- `EventDialog` の「[メリット]」の帯だけ消す … 他の人（丸山さん）のイベントの見た目に触れる。専用パネルのほうが、判定やカード表示も足せる。
- 7月に決めなかったら就職にする（現状のまま）… プレイヤーが決められなかった結果が、いちばん重い進路になる。
- 子どもの希望の「志望」を子カードに出さない … 山口さんの判断で出す。希望は夢から決まるので、夢が推測できるようになる（夢を隠す方針とはぶつかる）。

## 結果・影響

- 新規：`UI/PathPanelUI.cs`、`UI/GrowthGaugeLabelUI.cs`。変更：`PathDialogs`、`PathSystem`（`RecommendationOpen`、`AutoDecideByChild`、`TryGetCardLine`）、`SchoolBootstrap`、`GameDate.SchoolLabel`、`ChildCardUI`、`DebugDialogResolver`、Main_test2（Slider に文字2つ）。
- ADR 0038 の「判断の画面をイベントのダイアログで代用する」は、この ADR で置き換えた。
- 2月の自動決定・推薦の窓・子カードの進路の行は、日付を飛ばして確かめようとしたが、日付を飛ばすと成長の追いかけ計算で家出になってしまうため、最後まで通して確かめていない（コードの確認と、部分の確認のみ）。
- 学費・予備校代・私立高校の学費は、お金の担当（有坂さん）に任せる。引き継ぎメモは docs/team/path-money-handoff.md。
