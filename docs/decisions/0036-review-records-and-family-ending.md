# リザルトに家庭の結末と振り返り（成長グラフ・できごとの記録）を足し、図鑑と平凡の結末は作らない

## 背景
リザルト（result-scene.md）は職業・数字のまとめ・最終ステータスを流すだけで、子育ての20年を振り返る材料が無かった。
また、お金と親はこのゲームの要なのに、結末には親の稼いだ額しか出ていなかった。
ending.md 5.2 の既定の職業が「フリーター・模索中」で、伸びなかった子が「平凡」扱いになっていた。

## 決定
1. リザルトは **結果発表 → 振り返り** の2段。ランク・スコアは付けない。エンディング名は画面に出さない。
2. 結果発表に **家計の一文・子育ての一文・親の最終状態** を足す（review-records.md 3章）。母・父それぞれの一文は出さず、親ごとの **ストレスと働き方の移り変わり（グラフ）・役職の移り変わり** を振り返りで見せる。
3. 振り返りに **成長グラフ**（毎月の記録）と **できごとの記録** を足す。プレイ中に `LifeRecorder` が貯め、セーブにも入れる。
4. 振り返りは end シーンと **タイトル画面の育成記録** の両方から開ける。
5. **図鑑（コンプリート）は作らない。**
6. **平凡の結末は作らない。** 条件を満たす候補が無いときの既定の職業は **会社員**。

## 検討した他の案と、採らなかった理由
- エンディング図鑑（コンプリート） … コンプリートを目指す遊びは「子育てをがんばる」という本題からずれる。作る量も大きい。
- 総合ランク（S〜D） … 子育てに点数を付けることになり、本題と合わない。
- 既定の職業を「フリーター・模索中」のままにする … 「そんな人生はない」。どの子にも職業を付けたい。
- 職業ごとに必要資金を持たせる … お金はすでに進路（入学金・学費・奨学金）で効いているので、二重になる。

## 結果・影響
- 新規：docs/design/review-records.md
- ending.md 0章・5.2（既定の職業を会社員に、作家を候補に）
- result-scene.md 3章（EndingResult に項目追加）・5章（records.json を概要と詳細に分ける）
- title-screen.md 6章（詳細＝振り返り画面）
- EventManager（丸山さん担当）に「イベントを選び終えた」通知が必要
