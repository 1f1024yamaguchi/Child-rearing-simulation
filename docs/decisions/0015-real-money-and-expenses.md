# お金は実際の円で扱い、無償化は支出を減らす形で作る

## 背景
支援制度の支給額と申請条件を決めるにあたり、金額の単位、無償化の表し方、年収の決め方を決める必要があった。

## 決定
- 金額は実際の円。子育てにどれだけお金が必要かを学ぶ目的のため。
- 無償化系は、お金を配るのではなく支出を肩代わりする形で作る。そのために支出の仕組み（家計簿）を作る → [../design/expenses.md](../design/expenses.md)。
- 年収は直近12か月に実際に受け取った給料（母＋父）の合計（ワークライフバランスで増減する）。
- 所得条件は現実どおり少なめにする（学習目的のため）。
- （2026-10-06 追加）給料は手取りで入る（手取り率 0.8 たたき台）。年収の条件判定は額面。支出・家計簿の担当は山口。
- 家族は父・母・子ども1人の3人。ひとり親・子どもの人数は土台ができてから追加。

## 検討した他の案と、採らなかった理由
- ゲーム用に金額を調整した通貨 … 学習目的に合わない。
- 無償化をお金を配る形で作る … 「無償化でも給食費はかかる」などの現実が表せない。
- 年収＝役職の月給×12 … 働き方と制度の駆け引きが生まれない。

## 結果・影響
- support-apply.md 4.2.1・9章、expenses.md（新規）。
- `SupportScheme` に `covers`、Core に `IncomeHistory` / `ExpenseManager` / `Ledger` を追加予定。
