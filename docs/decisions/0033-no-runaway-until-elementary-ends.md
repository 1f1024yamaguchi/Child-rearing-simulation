# 小学生までは家出しない（中学入学から家出の判定を始める）

## 背景
子どものストレスが限界（91以上）のまま30日（たたき台）続くと家出＝ゲームオーバーになる。何も操作しないと0歳のうちに家出してしまい、プレイヤーがルール（スライダー・食事・支援制度・ミニゲーム）を覚える前にゲームが終わっていた。

## 決定
1. **小学生まで（12歳3月31日まで）は家出しない。** この期間はルールを覚える期間とする。
2. 中学入学（**12歳4月1日**）から家出の判定を始める。学年は4月始まり（ending.md 2.5章）。
3. それまではストレスが限界でも家出のカウントを進めない（0のまま）。「家出まで ○日」の警告も出ない。
4. ストレス自体はこれまでどおり上下する（成績・体調などへの影響は変わらない）。
5. 開始日は `RunawayWatcher` の Inspector（`activeFromAge` = 12 / `activeFromMonth` = 4）で変えられる。数値はたたき台。

## 検討した他の案と、採らなかった理由
- 小学生まではストレスが限界まで上がらないようにする … ストレスの意味（成績・体調への影響）まで変わってしまう。家出だけを止めれば足りる。
- 家出までの日数を年齢で長くする … 「いつから家出があるか」がプレイヤーに分かりにくい。

## 結果・影響
- コード：`Assets/Yamaguchi/Scripts/Core/RunawayWatcher.cs`（`ActiveFromDay` / `IsActive` を追加。判定前に日付を確認）
- ドキュメント：[docs/design/child-status.md](../design/child-status.md) 4章、[docs/design/rules-and-stats.md](../design/rules-and-stats.md) 1章
- 小学生のうちはストレスが限界でもゲームが続くので、「ストレスが高いと何が起きるか」を伝える演出（警告など）は別途検討する。
  → 家出の判定が始まる日（12歳4月1日）に家出のチュートリアルを出すことにした（[0034](0034-tutorial-panel.md)）。
