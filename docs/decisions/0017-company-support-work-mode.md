# 会社の制度は親の「働き方の状態」と給料連動の支給で作り、段階的に実装する

## 背景
育休・時短は「決まった額のお金が入る」今の制度の形では表せない（親の給料・働き方が変わり、給付は給料の○%）。

## 決定
- 親に働き方の状態（Normal／ParentalLeave／ShortTime）を持たせる。育休・時短中はワークライフバランスを0に固定する（時短はスライダーを一番ライフ寄りにしたのと同じ）。
- 給付は休む前の月給（役職の月給）に率を掛けて日割りで払う。手取り率は掛けない（非課税）。
- 誰が取るかは選べる（母用・父用のカード）。育休は子どもが1歳になるまで。マミートラックは入れない。
- 第1段階 育休 → 第2段階 出生後休業支援給付金 → 第3段階 時短 の順に作る。
- 詳細は [../design/company-support.md](../design/company-support.md)。

## 検討した他の案と、採らなかった理由
- 申請時に「誰が取るか」を選ぶダイアログ … 作りが増える。両親とも取っているかの判定もしにくい。
- 時短を別の給料計算にする … スライダーと二重の仕組みになる。

## 結果・影響
- ParentStatus / SupportScheme / SupportManager / GameContext / 親カードの UI に変更が入る（すべて山口の担当範囲）。
