# カレンダーにはプレイヤーが書いた予定だけを載せる

## 背景
カレンダーを Google カレンダー型（プレイヤーが「どの制度をいつまでに申請するか」を書き込む）にした（calendar-system.md 2.2〜2.5）。一方 0010 では「申請期限は最初から自動でカレンダーに載る」と決めていたため、自動で載ると書き込む意味がなくなる。

## 決定
- 制度の申請期限・定期手続きはカレンダーに自動では載せない。プレイヤーが書いた予定（2.2）と、制度カードの［カレンダーに追加］（2.3）で入れた予定だけを載せる。
- 期限そのものは制度カード（サポート画面）に表示する。
- 0010 の「先の月の分も最初から見える」は、制度については廃止。予防接種・行事は別に決める。

## 検討した他の案と、採らなかった理由
- A 自動で全部載せる（0010 のまま） … 書き込む意味が薄くなる。
- C 自動は薄く表示し通知は書いたものだけ … 表示が複雑。現実に近いのは B。

## 結果・影響
- calendar-system.md 3章・7章を修正。0010 の該当部分はこの決定で置き換え。
