# 洗濯機故障イベントの費用見直しと説明文改定

## 背景
突発デメリットイベント「洗濯機が壊れた（`demerit_sudden_expense`）」において、従来の費用設定は「買い替え: -40,000円 / 修理: -12,000円」となっていたが、現実のドラム式・全自動洗濯機の購入相場や出張修理費用と比較して低すぎた。
家計管理シミュレーションとしての現実感・手応えを高めるため、費用設定とイベント説明文を見直す要望があった。

## 決定
1. **費用の改定**:
   - 新しく買い替える（c1）: **80,000円**（`-80000`）
   - 修理して様子を見る（c2）: **25,000円**（`-25000`）、親ストレス +4（維持）
2. **文面の対応**:
   - 説明文を「毎日使う洗濯機が、突然動かなくなった。新しく買い替えるか、修理を頼むか……」に改定。
   - ボタン表示時も自動で `新しく買い替える (-80,000円)`、`修理して、しばらく様子を見る (-25,000円)` と金額が明示される。
3. **有坂担当フォルダへの定数配置**:
   - 家計・支出設定の管轄として、`Assets/Arisaka/SuddenExpenseSettings.cs` を新設し、家電等の特別支出定数を一元管理。
4. **仕様書・ビルダーの同期**:
   - `Event_Demerit_SuddenExpense.asset`、`EventAssetBuilder.cs`、`docs/design/events.md` を同期更新。

## 結果・影響
- 洗濯機故障イベントが発生した際のインパクトがより現実的な家計負担（8万円／2.5万円）となり、プレイヤーの突発出費への備えや選択の重みが増した。
