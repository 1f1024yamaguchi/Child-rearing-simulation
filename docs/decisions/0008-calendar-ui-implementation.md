# カレンダー画面のUI構成と時間停止連動の実装

## 背景

カレンダー画面のUI実装において、Qiita記事「【Unity】カレンダーの作成」(hire1105) の42マスグリッド方式をベースとしながら、ゲーム内の独自暦（`GameDate`）および時間停止決定（[0004-pause-during-decisions.md](0004-pause-during-decisions.md)）との連動を行う必要があった。

## 決定

1. **ファイル配置と担当責務**: カレンダーUIを `Assets/Kusao/CalendarUI.cs` に配置し、草尾の担当作業領域で完結させる。
2. **時間停止の連動**: `CalendarUI` の `OnEnable` で `GameClock.Instance.PushPause()`、`OnDisable` で `GameClock.Instance.PopPause()` を呼び出すことで、カレンダーが開いている間のみ確実に時間の進行を停止する。
3. **デザインとUI要件**:
   - 曜日ヘッダーは不要との要件に基づき省略。
   - タイトル部に「〇歳 〇月」、前月・次月切り替えボタン、右上に「✕」閉じるボタンを配置。
   - HUDのカラーパレット（シアン・グレー系）と調和する配色に統一し、今日のセルをアクセントカラーで強調。
4. **日付計算**: `GameDate` に月日数取得 (`DaysInMonth`) および通算日数変換 (`ToAgeDays`) を追加し、自前での日付計算を行わず共通ロジックを参照する。

## 検討した他の案と、採らなかった理由

- **`GameClock.SetRunning(false)` を直接呼ぶ** … ADR 0004に反し、複数のモーダルが開いた際に時間の再開タイミングが破綻するため採らなかった。
- **曜日の色分け（土日カラー）を導入する** … ユーザーから「曜日は入れなくて大丈夫」と明記されたため、シンプルな日付中心のグリッド表示を採用した。

## 結果・影響

- メイン画面の「カレンダー」ボタンから `CalendarUI` モーダルが正常に起動・閉じるようになり、閲覧中は時間進行が停止する。
- 関連ドキュメント `docs/design/calendar-system.md` の更新を行った。
