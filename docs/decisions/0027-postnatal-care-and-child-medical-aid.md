# 産後ケアと子ども医療費助成をゲーム用の簡略モデルとして定義する

## 背景

産後ケア事業と子ども医療費助成を追加候補としたが、利用料金や対象条件には自治体ごとの差がある。東京都内の市区町村共通制度として実在条件を一律に設定せず、ゲーム上の仮定と現実の制度情報を区別する必要がある。

## 決定

- 産後ケア事業は、宿泊・通所・訪問の違いを分けず、0歳の間に1回利用できる単一サービスとして扱う。
- ゲーム内の産後ケア利用料は1回5,000円とする。これはゲーム上の仮値であり、東京都共通の実利用料や相場を示すものではない。
- 利用時に母の現在のストレスを10%軽減する。例えばストレスが60なら54になる。これは固定値10ポイントの減少ではない。
- 子ども医療費助成は、東京都全体を想定したゲーム用モデルとして扱う。申請後、18歳到達後最初の3月31日まで、健康保険適用後の自己負担分を全額助成し、所得制限を設けない。申請日以降に発生した費用に適用し、遡及適用しない。保険適用外の費用は対象外とする。
- 上記の医療費モデルはゲーム上の簡略化であり、東京都内の全自治体で実制度の条件が同一だと主張するものではない。
- 特別支援教育就学奨励費は、教育環境と対象条件の設計が決まるまで保留する。再検討時の費目候補は通学費とし、現時点では金額・効果・申請条件を定めない。

## 検討した他の案と、採らなかった理由

- 東京都内の特定自治体の制度をそのまま採用する … ゲーム全体の地域設定を特定自治体に限定する合意がないため。
- 特別支援教育の対象条件を診断名や既存ステータスに結びつける … ゲーム内の教育環境・対象条件がまだ設計されておらず、推測で定めないため。
- 産後ケアのストレス効果を固定値で減らす … 今回は現在のストレスに対する10%軽減を希望したため。

## 結果・影響

- [support-apply.md](../design/support-apply.md) にゲーム用の条件と実装状況を記録する。
- 産後ケアのストレス効果は [決定0028](0028-postnatal-care-stress-fixed-reduction.md) で固定値に変更した。産後ケアは0歳の間に1度だけ申請できる制度アセットとして `Main_test2` に登録する。
- `MedicalExpenseCover` と `SupportManager.MedicalExpenseCoverage` を追加し、病気イベントで保険診療の自己負担と明示された費用を助成する。実際の支払額と助成額は同じ家計簿行に記録する。
- 特別支援教育就学奨励費の仕様確定は、教育環境の設計後に行う。
