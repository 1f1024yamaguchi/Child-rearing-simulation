# 生まれた日（0歳1月1日）を月曜日とし、7日周期で曜日を回す

> ※ 元は `0008` として作成したが、同じ日に別の `0008`（[0008-calendar-ui-implementation.md](0008-calendar-ui-implementation.md)）が作られたため `0012` に付け替えた（2026-09-25）。

> ⚠ **廃止（2026-09-25）。** カレンダーは曜日を表示しない形で実装され（[0008-calendar-ui-implementation.md](0008-calendar-ui-implementation.md)）、その形で確定したため、曜日そのものを使わなくなった。

## 背景
カレンダー機能（[../design/calendar-system.md](../design/calendar-system.md) 6章）は、Qiita 記事の方式で 7列×6行のグリッドに日付を並べ、土日を色分けする。
しかしゲーム内の暦（`GameDate`）は「0歳1月1日起点・1年365日・うるう年なし」で現実の日付と無関係なため、**曜日が存在しなかった**。

## 決定
- 生まれた日は **0歳1月1日** のまま変えない。
- その日を **月曜日** とし、以降は通算日数から 7日周期で曜日を決める。
- 実装：`GameDate.BirthDayOfWeek = 1`（0=日 … 6=土）、`DayOfWeek(ageDays) = (ageDays + BirthDayOfWeek) % 7`。

## 検討した他の案と、採らなかった理由
- 曜日を持たない（土日の色分けをしない） … 実際のカレンダーアプリに近い見た目にしたい（calendar-system.md 1章）ので採らない。
- 現実の日付（`DateTime`）に紐づける … うるう年などで `GameDate` とずれる。日付計算を2系統持つことになるので採らない。

## 結果・影響
- 1年が 365日（52週＋1日）なので、毎年1月1日の曜日は1つずつずれる（1歳1月1日＝火曜）。
- 将来「平日／休日」で効果が変わる仕組み（学校行事、親の休日など）を入れる場合も、この曜日を使う。
- `GameDate` への関数追加が必要（calendar-system.md 6.3）。
