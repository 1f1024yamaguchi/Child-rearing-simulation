# 産後ケアのストレス効果を固定値10減少にする

## 背景

産後ケアの効果を現在のストレスに対する割合軽減として実装していたが、割合を扱う専用の効果種別を増やすより、固定値の効果として扱うことにした。

## 決定

- 産後ケア利用時に母のストレスを固定値で10減らす。
- ストレスの増減は共通の `Stress` 効果を使い、`value = -10` とする。これは10%ではなく10ポイントの減少を表す。

## 検討した他の案と、採らなかった理由

- 現在のストレスの10%を減らす … 今回の指定が固定値 `-10` のため。

## 結果・影響

- `StressPercentReduction` 専用の効果種別と適用処理を取り除き、丸山担当の `EffectApplier` は固定値のストレス効果を扱う従来の形に戻す。
- 産後ケアの制度アセットと [support-apply.md](../design/support-apply.md) を固定値減少に合わせる。
- 子ども医療費助成のイベント連携は維持する。
