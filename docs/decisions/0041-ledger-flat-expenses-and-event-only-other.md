# 家計簿の毎月支出の独立表示と「その他」カテゴリのイベント限定化

## 背景
従来の家計簿画面（月タブ・年タブ）では、`ExpenseCategory` ごとに大枠の見出し（「住居」「光熱費」「その他」など）を表示し、その下に個別の支出行をインデント表示する2重階層構造をとっていた。
そのため、「住居」の下に「家賃」、「光熱費」の下に「光熱・水道」という冗長な表示が発生していた。

さらに、総務省家計調査データ（budget01〜12）に基づく生活変動費（家具・家事用品、被服及び履物、交通、教養娯楽、諸雑費）がすべて「その他」カテゴリに分類されていたため、「その他」の中に毎月の生活費とイベント起因の突発出費が混在し、「何にいくらかかっているのか」が直感的に把握しにくい問題があった。

## 決定
1. **毎月かかる支出の独立表示（親カテゴリ見出しの廃止）**
   - 家賃、光熱・水道、家具・家事用品、被服及び履物、保健医療、交通、通信、食費、教育、教養娯楽、諸雑費、保育料、給食費など、毎月かかる支出は「住居」「光熱費」等の親カテゴリ見出しで束ねず、項目名（`l.source`）を直接独立した行としてフラットに表示する。
   - 表示順は生活費・固定費の自然な順序（住居→光熱費→家具→被服→医療→交通→通信→食費→保育→学校→塾→教養娯楽→諸雑費）に整列する。
2. **`ExpenseCategory` の拡張と生活費の独立分類**
   - セーブデータの後方互換性を保ちつつ末尾に `家具家事用品(12)`, `被服履物(13)`, `交通(14)`, `教養娯楽(15)`, `諸雑費(16)` を追加。
   - `MonthlyLivingExpenseManager` で引き落とす月別生活費をこれらの独立カテゴリに紐付け、「その他」には入らないようにする。
3. **「その他」カテゴリのイベント限定化**
   - 「その他」カテゴリは維持するが、そこに入るのは**イベントで発生した突発的な支出（`ExpenseCategory.その他`）のみ**とする。
   - 月タブでは、その月にイベント出費が発生した場合のみ「その他」見出し＋小計＋個別行を表示し、発生しなかった月は非表示とする。
   - 年タブでは、その年にイベント出費があった場合のみ「その他」アコーディオン見出しを表示し、クリックしてイベントごとの内訳（家電買い替え、入院等）を展開確認できるようにする。

## 検討した他の案と、採らなかった理由
- **全支出を完全な1階層フラットリストにし、「その他」カテゴリ見出しも完全廃止する案**
  - 採らなかった理由：突発的なイベント出費（「新しく買い替える」「病院に行く」等）は月や年によって発生有無や件数が異なり、それらを「その他（イベント出費）」としてまとめて小計を把握したいプレイヤーの要望に合致しないため。
- **`ExpenseCategory` enum を変更せず、表示コード側だけで名前判定してグルーピングを解除する案**
  - 採らなかった理由：データモデル上「その他」に毎月の生活費が集計され続け、将来の統計・セーブデータ・グラフ等で生活費とイベント突発費を分離できなくなるため。enum を正しく拡張して分離した。

## 結果・影響
- `Assets/Yamaguchi/Scripts/Core/Ledger/ExpenseCategory.cs`: 12〜16を追加（セーブ互換維持）。
- `Assets/Arisaka/MonthlyLivingExpenseManager.cs`: 9項目の生活費のカテゴリ設定を独立区分に更新。
- `Assets/Yamaguchi/Scripts/UI/Ledger/LedgerMonthView.cs`: 毎月の支出行を生活費順に独立表示し、「その他」はイベント出費専用として発生時のみ表示。
- `Assets/Yamaguchi/Scripts/UI/Ledger/LedgerYearView.cs`: 毎月の支出行の年間合計を独立行で直接表示し、「その他」のみイベント出費アコーディオンとして表示。
- プレイヤーにとって家計簿の視認性が大幅に向上し、毎月の固定・変動生活費とイベントでの突発費が明確に区別できるようになった。
