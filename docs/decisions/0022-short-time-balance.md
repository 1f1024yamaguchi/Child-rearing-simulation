# 時短勤務中のワークライフバランスを0.2に固定する

## 背景

旧決定では育休・時短勤務のどちらもバランスを0に固定していた。その後、時短勤務は「休み」ではなく、短い時間で働いて通常日給の80%を得る状態として仕様を具体化した。

## 決定

- 産休・育休中はバランスを0に固定し、日給を0にする。
- 時短勤務中はバランスを0.2に固定し、通常勤務の日給の80%を得る。
- いずれも勤務状態に応じてスライダーを操作不可にし、通常勤務へ戻ると勤務状態になる前のバランスへ戻す。
- 詳細は [company-support.md](../design/company-support.md) を正とする。

## 検討した他の案と、採らなかった理由

- 時短勤務もバランス0にする … 休業と時短の区別がバランス値から分からず、通常日給の80%という仕様とも一致しない。

## 結果・影響

- [0017](0017-company-support-work-mode.md) の「時短勤務中もバランス0にする」という部分を置き換える。
- `ParentStatus`、親カードの表示、時短制度アセット、会社制度の設計書は、時短勤務中をバランス0.2・日給80%として扱う。
