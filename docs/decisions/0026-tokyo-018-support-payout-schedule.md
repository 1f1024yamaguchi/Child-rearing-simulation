# 018サポートは4・8・12月に対象月分をまとめて支給する

## 背景

東京都018サポートは月額5,000円を対象月数分まとめて支給する。ゲームの既存支援制度は申請翌月から毎月支給する仕組みで、実際の支給間隔を表せなかった。

## 決定

- 018サポートは月ごとに対象額を積み立て、ゲーム内暦の4・8・12月にまとめて支給する。これは現実の4月・8月・12月の支給月に対応させる。
- ゲーム内暦は子どもの出生を0歳1月1日として始まるため、現実の暦月ではなく月番号を対応させる。
- 対象判定は既存ルールに従い申請月の翌月から行い、申請月分の遡及支給はしない。
- 未支給の積立額はセーブ対象にする。既存の毎月支給制度は設定を空にし、現行の挙動を維持する。

## 検討した他の案と、採らなかった理由

- 毎月5,000円を支給する … 東京都の実際の支給間隔と異なる。
- 既存の全支援制度をまとめ払いにする … 制度ごとに支給方法が異なるため、018サポートだけに設定できる形にする。

## 結果・影響

- `SupportScheme.payoutMonths` が空なら従来どおり毎月支給し、指定があればその月に積立額を支給する。
- `SupportSchemeRuntime` に未支給額と最終積立月を保存する。
- 018サポートのアセットを追加し、`Main_test2` の支援制度一覧に登録する。
- 月ごとの積立額・次回支給月を制度カードに表示する。
