# 家計簿画面（月ごと・年ごと）の UI 構成とデータ集計方式

## 背景
子育てとお金の実感をプレイヤーに体感してもらうため、家計簿画面（[../design/expenses.md](../design/expenses.md) 5章・依頼E5）が必要になった。
当初は誕生日のまとめ画面を予定していたが、家計簿の［年］タブで1年分のお金の動き（月ごとの支出グラフ、税金のまとめ、種類別の支出）が確認できるため、［月］と［年］を切り替えるタブ画面として構築した。

## 決定
1. **テキストはすべて TextMeshPro（JPFont）**：
   - レガシーの Text は使わず、`TextMeshProUGUI` で統一。
   - 開くボタン（`Canvas/Buttons/Kakeibo`）のフォントも JPFont に揃える。
2. **データの集計は Ledger 側に持たせる**：
   - 画面側で複雑な計算をせず、Ledger から `LinesOfMonth`、`LinesOfYear`、`MonthSummary` を取得して並べる。
   - `Ledger` は直近24か月分の行保持に加え、年ごとの行合計（`yearLines`）と月ごとの合計（`monthSummaries`）を保持・セーブ可能にした。
3. **月の画面（［月］タブ）**：
   - ‹ › で直近24か月の行を移動。
   - 左に給料（額面）、税金社会保険、支援制度。
   - 右に支出を種類別（見出し＋小計＋個別行。0円で肩代わりもない行は非表示）。
   - 下部に手取り・支援・支出・差し引きと、支援で助かった額、子育てにかかったお金。
4. **年の画面（［年］タブ）**：
   - ‹ › で 0歳〜現在の年を移動。
   - 12か月の支出の棒グラフを配置（棒をクリックするとその月の［月］タブへジャンプ）。
   - 左に収入、税金（「年末調整」「確定申告の還付」を別行にし、1年の税金合計を表示）、支援制度。
   - 右に支出の種類別1年合計（種類行をクリックするとアコーディオンで個別行を展開）。
5. **時間停止**：
   - `LedgerPanelUI` の `OnEnable` / `OnDisable` で `GameClock.I.PushPause()` / `PopPause()` を呼び、画面が開いている間は時間を停止する。
6. **エディタ拡張による自動生成**：
   - `LedgerUIBuilder.cs` により、メニューからプレハブ生成とシーンへの配置・ボタン配線を1ステップで行えるようにした。

## 結果・影響
- プレイヤーはお金の表示下の［家計簿］ボタンから、月ごと・年ごとの家計収支（電気代・ガス・食費・保育料・税金・年末調整）をいつでも詳細に確認できるようになった。
