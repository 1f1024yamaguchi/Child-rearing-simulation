# ゲームの終わりを「20歳」から「子どもの巣立ち」に変え、進路で巣立つ年齢を変える

## 背景
[rules-and-stats.md](../design/rules-and-stats.md) 1章では「7300日＝20歳でエンディング」とし、成績・趣味の高さで「博士／スポーツ選手／音楽家…」に分岐する案だった。
しかしエンディング判定の設計に入ると、次の問題が出た。

- 20歳には区切りとしての意味が薄い。高卒で就職した子は18歳で家を出ており、大学生は20歳でもまだ親が学費を払っている。
- 大学に行くのが前提のようになってしまう。現実には高卒就職・専門学校も多い（令和7年度学校基本調査：大学・短大等 62.6%／専修学校等 18.6%／就職 13.8%）。
- 20歳で「博士」は現実にありえない。
- 子どもが何の職業になったかを、リザルトで見せたい。

## 決定
- ゲームの終わりは **子どもが親元を離れた日（巣立ち）**。20歳固定にしない。
- 高3の7月に進路（就職／専門学校／大学／推薦）を決め、**進路で巣立つ年齢を変える**（高卒 18歳3月末／専門卒 20歳3月末／大卒 22歳3月末）。
- 大学に進んだら **22歳まで実際にプレイし、学費も払い続ける**（エピローグで済ませない）。
- 巣立ちの日に職業を判定し、リザルトで「○○になった」と流す。夢が叶った／叶わなかったという言い方はしない。
- あわせて決めたこと：
  - テストは小学校が通知表だけ、中高が学期末テスト年3回。中3の2月に高校受験（公立か私立か）
  - 受験の合格ラインは進路ごとに持ち、合否は確率で決める（セーブ＆ロードでのやり直しは許す）
  - 大学に落ちたら浪人／就職／専門を選ぶ。中退と高校の種類の選択は入れない
  - 奨学金・修学支援は実際の制度の金額・条件に合わせる
  - 職業の条件はプレイヤーに見せない。将来の夢は職業名だけ見せる

詳細は [ending.md](../design/ending.md)。

## 検討した他の案と、採らなかった理由
- 20歳で終了のまま … 上の背景のとおり、高卒就職・専門の子にとって不自然。
- 高校卒業（18歳）でプレイを終え、その後はエピローグで見せる … 全員が同じ長さで遊べて作りも簡単。しかし大学の学費の重さをプレイで体験できず、「お金と子の幸福」というテーマが弱くなる。
- 合否をラインちょうどで確実に決める … 結果が事前に分かり、「挑戦させるか、確実な道にするか」の判断が生まれない。確率なら、後から値だけで確実な判定に戻せる。

## 結果・影響
- `GameState.GoalAgeDays` は固定 7300 ではなくなる。進路が決まる前は高校卒業の日、決まった後はその進路の巣立ちの日にする（[ending.md](../design/ending.md) 6章）。**コードは未変更。**
- HUD の成長ゲージ右端の「20歳」は「高校卒業」→「巣立ち」の表記になる。
- プレイ時間が進路で変わる（大学ルートは高卒ルートより約24分長い）。
- [rules-and-stats.md](../design/rules-and-stats.md) 1章（20歳でのエンディング・分岐表）、[child-status.md](../design/child-status.md) 5章（テストの時期）、[support-apply.md](../design/support-apply.md) 9.2（高校就学支援金の私立の上限）を更新した。
- 私立高校の学費の段を [expenses.md](../design/expenses.md) に足すのは、高校受験を作るとき。
