# 毎月1日の食事選択強制イベントと給料日引き落としの実装

## 背景
子どもの健康・発育や家計の意思決定要素として食事システム（有坂担当）を導入するにあたり、毎月1日にプレイヤーへ食事プランの選択を求め、選択完了までゲームの進行を停止する仕組みが必要であった。また、家計のリアルな収支管理に合わせ、食事費用の引き落としタイミングやアイコン表現の調整が必要となった。

## 決定
1. **担当ディレクトリの遵守**:
   すべてのスクリプトを `Assets/Arisaka/` 内に配置（`MealPlan.cs`, `MealCardUI.cs`, `MealSelectionDialogUI.cs`, `MealSystemManager.cs`）。
2. **毎月1日のトリガーと一日ごとの日割り引き落とし**:
   - `MealSystemManager` が `MonthTicker.OnMonthChanged` および `DayTicker.OnDayPassed` を監視。
   - **費用（コスト）の消費タイミング**: 選択された食事プランの月額費用をその月の日数（28〜31日）で日割りし、`EffectApplier.Apply` 経由で**一日ごとに所持金から引き落とす**（月末に合計が月額費用と完全に一致するよう累積差分で計算）。
   - **最新資産の表示**: 毎月1日には給与が反映された最新の所持金をダイアログ上部に表示した上で、プレイヤーに今月の食事選択を行わせる（初日の日割り食費は選択時に引き落とし）。
3. **プラン名とアイコンの変更**:
   - グレード名：**安価**（30,000円/月）、**普通**（90,000円/月）、**高価**（150,000円/月）
   - アイコン：各カードのアイコン枠（灰/薄黄/薄赤背景）の中央に、添付画像に忠実な「スープボウルから3本の湯気が出ている線画スプライト」を描画。
4. **枠線表示とボタンラベルの統一**:
   - **初回（1回目）**: 青い枠線は表示せず、すべてのボタンを「これにする」で統一。
   - **2回目以降**: 先月選択したカードに少し薄くした青枠を表示し、同じ薄青色で「先月に選択」ラベルを明記。ここでもボタンはすべて「これにする」で統一（継続・変更のどちらも同じ操作感で選択可能）。
5. **程よいサイズ感**:
   - カレンダー画面（560x440）を意識し、全画面を占有しない程よいサイズ感（720x460）のコンパクトなモーダルに調整。
6. **判断画面での時間停止**:
   Decision 0004 に準拠し、`MealSelectionDialogUI` の `OnEnable` で `GameClock.I.PushPause()`、`OnDisable` で `PopPause()` を呼び出して画面表示中に確実に時間を停止する。
7. **効果の共通モデルとデータ管理**:
   Effect モデル（docs/design/effects.md）に準拠し、効果は `EffectApplier.Apply` 経由で行う。表示テキストは直感的な色分け（悪化・増加＝赤、回復・Good＝緑、変化なし＝通常色）を適用する。
   - **安価**: 月額 30,000円（当月日数で日割りし毎日引き落とし）、「ストレス値 +5」（赤色、全員）、「Badイベント発生率+5%」（赤色、当月）
   - **普通**: 月額 90,000円（当月日数で日割りし毎日引き落とし）、「ストレス値 -2」（回復の緑色、全員）、「イベント発生率　変化なし」（通常色、当月）
   - **高価**: 月額 150,000円（当月日数で日割りし毎日引き落とし）、「ストレス値 -5」（回復の緑色、全員）、「Goodイベント発生率+5%」（緑色、当月）

## 検討した他の案と、採らなかった理由
- **各月の初日に自動でお金を引くだけで画面は出さない案** … 食事選択の判断がゲームプレイの重要要素であるため、プレイヤーへの能動的な選択を強制する形とした。
- **月末や翌月給料日に一括引き落とす案** … 毎日の生活感や日々の家計の変動をリアルタイムに感じられるよう、当月の日数で日割りして一日ごとに引き落とす方式を採用した。
- **GameState を直接叩いて数値を減算する案** … プロジェクト全体のコーディング規約（Effect モデルと EffectApplier による一元管理）に反するため不採用。

## 結果・影響
- どのシーンでも `MealSystemManager` が常駐し、毎月1日に添付写真デザインのモーダルダイアログが起動して時間が停止する。
- プラン決定後はその月の日数に応じて毎日自動で食費が引き落とされ、家計のリアルな日々の出費が再現される。
- ドキュメント [docs/design/food-system.md](../design/food-system.md) に最新仕様を反映。
