# スポットライト型スタートガイド（TutorialGuide）

ゲーム開始直後に自動で時間が止まり、画面上の文字数字（お金・日付・ゲージ）や下部の3大機能ボタン（サポート・カレンダー・家計簿）を**スポットライト（周囲を暗くくり抜き）＋ポップアップ解説**で案内するチュートリアルシステム。

- 保存場所：`Assets/Kusao/TutorialGuide/`
- メニュー：**「子育て → チュートリアル → スタートガイドを作成・設定」**
- チュートリアル用 Canvas のルートは画面全体を覆うため、RectTransform を全画面ストレッチ、スケールを `(1, 1, 1)` に保ちます。ルートが左下固定・サイズ 0 だと暗幕の配置領域がなくなり、暗幕が表示されません。実行時にもルート設定を補正します。

---

## 1. 特徴と仕組み

1. **特定ボタン以外のクリックを完全遮断**:
   - 4枚の暗幕パネル（Top, Bottom, Left, Right）に対象の RectTransform 以外の領域を覆わせ、`raycastTarget = true` でクリックを吸い取ります。
   - 初回表示時の初期化では暗幕パネルだけを隠し、Spotlight 本体を再び無効化しないようにします。
   - プレイヤーは「今指示されているボタン」と「チュートリアルポップアップ」以外をタップできなくなるため、誤操作の心配がありません。
2. **プレイヤー操作と画面連携**:
   - 「サポートボタンを押してみましょう！」というステップでは、プレイヤーが実際にボタンを押すとサポート画面が開き、チュートリアルも自動で「サポート画面の中身解説」へ進みます。
   - 中身の解説が終わって［次へ］を押すと、開いていた画面は自動で閉じられます。
3. **時間停止（PushPause / PopPause）**:
   - ガイド実行中はゲーム内時間を一時停止し、完了時またはスキップ時に再開します。
4. **初回のみ自動起動 ＆ セーブ記録**:
   - `PlayerPrefs` に閲覧済みフラグ（`Tutorial_SystemGuide_Viewed`）を保存。2回目以降は自動では立ち上がりません（Inspector の `Force Show On Start` を ON にすればテスト時に毎回実行可能）。

## 3. シーンへの導入方法

### 方法A: メニューから作成（推奨）
1. メインシーン（`Main_test2` など）を開く。
2. メニュー **「子育て → チュートリアル → スタートガイドを作成・設定」** を実行。
3. シーン上に `TutorialGuide_Canvas` が生成・配線され、プレハブ `Assets/Kusao/TutorialGuide/TutorialGuide_Canvas.prefab` が更新されます。
4. シーンを保存する。

### 方法B: 実行時フォールバック
シーンに `TutorialGuide_Canvas` を配置していなくても、Play 時にメイン画面（Canvas）があれば `TutorialGuideController` が自動生成されて自走します。

## 5. ボタン周りのズレ修正・微調整方法（Inspectorでの調整）

ボタンや文字のハイライト枠（スポットライト）が少しズレている場合、**Unity の Inspector 上で自由に調整・修正できます。**

1. シーン上の `TutorialGuide_Canvas` を選択する。
2. `TutorialGuideController` コンポーネントの **`Steps`** リストを展開する。
3. 調整したいステップ（例: Step 0: `money`, Step 5: `support_btn` など）を開く。
4. 以下の項目でミリ単位の微調整が可能です：
   - **`Position Offset` (X, Y)**: スポットライト枠の位置を上下左右にズラします（X で左右、Y で上下）。
   - **`Padding` (X, Y)**: スポットライト枠の横幅・縦幅のサイズ余白を広げたり狭めたりします。
   - **`Target Rect`**: シーン内のボタンやテキストの RectTransform を直接ドラッグ＆ドロップして指定することも可能です。
   - お金の対象は `money_text` を優先して枠を合わせ、金額テキストが見つからない場合だけ `money` 親を使います。
   - 点滅枠の最大の濃さは `TutorialGuideSpotlight` の `Border Color` のアルファ値で調整できます。

> [!TIP]
> **Play（ゲーム再生）中にもリアルタイム調整が可能！**
> Unity でゲームを再生中、チュートリアルが表示されている状態で Inspector の `Position Offset` や `Padding` の数値を動かすと、**画面上のスポットライト枠がリアルタイムに動きます**。実際のボタンの見た目を確認しながらピッタリ合わせられます。調整した数値をメモするか、コンポーネントの値をコピーして停止後に貼り付けて保存してください。

## 6. 食事選択画面（今月の食事）との表示順制御

ゲーム開始時（0歳1月1日）に `MealSystemManager` が開く「食事選択ダイアログ」は、チュートリアル実行中は自動的に一時非表示（退避）されます。
チュートリアルが完了（またはスキップ）した瞬間に退避されていた食事選択画面が再表示されるため、HUDの全体説明を遮ることなくスムーズにゲーム本編へ移行できます。
